初始 · Start-chushi — 预设开发工具（内嵌离线版）

使用说明

这是「初始」官方的图形化预设开发工具：不需要手写 JSON，填表单即可生成一份完整、合法的预设文件。本工具为单文件离线应用——从「初始」的导入预设面板点击「图形化开发工具」下载后，双击即可在任意浏览器打开，无需联网。

三步上手

  1. 在左侧表单填写内容：基础信息、⌘K 命令 / 磁贴 / 栏按钮、焕新四件套（图标 / 主题令牌 / 动效语言 / 时钟格式）、自定义样式与脚本；
  2. 右侧实时生成 JSON 并给出完整性提示，确认无误后点「下载 .cshz 包」（也可下载 .json 或直接复制）；
  3. 回到「初始」→ ⌘K → 预设系统 → 导入预设：把 .cshz 包拖进面板（或粘贴 JSON、选择文件）。删除预设即整体还原。

换材质（材质作用面）

宿主不内建任何具体材质；「初始」提供通用材质接口，任何风格（亚克力 / 液态玻璃 / Win UI Mica 等）都由预设脚本经它实现。在脚本中：

await chushi.material.apply({
  css: `
    .search-pill, .cl-dock, .cl-panel, .glass-card {
      backdrop-filter: blur(40px) saturate(1.6);
      background: linear-gradient(135deg, rgba(255,255,255,.6), rgba(240,245,255,.38));
      border: 1px solid rgba(255,255,255,.55);
    }`
});
// chushi.material.reset() 可主动摘除；删除预设时宿主自动回收

css 直接使用公开元素钩子（.search-pill / .cl-dock / .cl-panel / .glass-card）。高级折射类材质（位移贴图）可配合 chushi.fx.onResize 快照按 data-fx 标记动态构造 SVG 滤镜——参考开发者文档（⌘K → 预设系统 → 开发者文档）。

注意

  • .cshz 是「初始」官方预设包格式（zip 结构：manifest.json 必需 + assets/ 可选资源目录）。本工具导出的包把预设主体作为 manifest.json 打包，可直接拖进「初始」的导入面板；带图片等资源的高级包可参考开发者文档。
  • 右侧提示只是辅助——最终以「初始」导入时的整体校验为准，校验失败会列出每条错误。
  • 请尊重安装者：不要做高频通知、抢焦点之类的体验。
