# 「初始」v8.7.21 使用说明（音乐桥抗休眠终局 + 全局歌词玻璃拉伸/切行模糊 + 两处误触修复）

## 本版修了什么（全部来自你的实机反馈）

### ① 网易云最小化一段时间后，「初始」无法控制音乐播放等操作
上一版（8.3.5）把桥的心跳搬进了 Web Worker，理论上后台不被节流；但新版
Chromium 把「最小化窗口里的 Worker 定时器」也纳入了同档强节流——最小化
超过五分钟后，Worker 心跳和页面定时器一起被钳到每分钟一次，桥照样停摆，
这就是你遇到的「最小化一会儿就控制不了」。

本版把心跳彻底搬出了定时器体系：**音频线程心跳**。桥在网易云页面里挂了一
条极轻的正弦波（55Hz、约 -50dB，人耳听感为零，和正在放的音乐完全不冲突），
音频渲染线程按硬件回调持续运转、**不受任何页面可见性节流**，由它按拍唤醒
主线程去推状态、取命令。同时窗口回到前台的瞬间会立刻补一轮状态+命令，
恢复零等待。

**本版桥必须升级到 8.4.0**（ChuShi-Music-Bridge-8.4.0.plugin）：
关闭网易云 → 把插件目录里的旧版文件替换为新包内容 → 重启网易云。
不升级桥的话，最小化休眠问题依旧（扩展侧无法单方面根治）。

### ② 打开更新日志时内容「复位」
两刀修复：a) 更新日志列表滚到顶/底之后继续滚动，不再把半透明纱罩后面的
设置面板一起拖着滚（背景内容滑动就是你看到的「复位」感）；b) 本次打开
页面期间，关闭更新日志再打开，会回到你上次读到的位置，不再每次都跳回
最新版本顶部。

### ③ 打开抽屉后在抽屉页面双击会进入禅模式
链接抽屉（中键唤出的磁贴墙）打开时，在墙面空白处双击不再误触禅模式；
磁贴本身的双击/打开行为不受影响。禅模式照旧：页面空白处双击进出。

### ④ 全局歌词动画四连
- **玻璃拉伸**：歌词长度变化时，磨砂玻璃药丸会平滑地拉伸/收缩到新长度，
  且视觉中心保持不动（向两边对称生长），不再是生硬的跳变；
- **药丸居中修复**：无歌词状态（♪ 歌名·歌手）下，首次使用的药丸现在
  精确居中于屏幕——旧版因定位时序竞态会停在一个偏侧的假设位上；
- **药丸↔歌词态切换**：与玻璃拉伸共用同一套动画，两种形态之间平滑过渡；
- **切行模糊过渡**：每次切到新的一句歌词，新句带模糊聚拢淡入（0.42s），
  配合玻璃拉伸，逐句切换更柔和。系统「减弱动态效果」开启时自动停用。

## 升级方式
- 扩展：覆盖安装 ChuShi-NewTab-v8.7.21.zip（或解包后开发者模式加载）；
- 音乐桥：ChuShi-Music-Bridge-8.4.0.plugin 替换旧插件目录后重启网易云（必升）；
- 音乐预设部件：ChuShi-Music-Preset-8.7.21.cshz（与上一版内容一致，可跳过）；
- 全家桶：ChuShi-v8.7.21-AllInOne.zip 一次拿全。
