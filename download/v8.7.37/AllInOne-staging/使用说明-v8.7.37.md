# 初始 · Start v8.7.37 交付说明（beta）

## 本包内容
- ChuShi-NewTab-v8.7.37.zip —— 扩展本体（本版：流畅模式根治三连+辉光互斥+书签翻页+Alt+V）
- ChuShi-CloudSnapshot-v8.7.37.zip —— 云端快照载荷
- 初始SMTC音乐预设.cshz —— SMTC 桥接音乐面板预设（存量）
- 初始网易云播放器预设.cshz —— 网易云 dock 弹出播放器预设（存量）
- 焕新示例预设.json —— 八维焕新示例预设（存量）
- ChuShi-Music-Bridge-8.4.0.zip —— 音乐桥插件（存量）
- ChuShi-Lyric-Source-7.3.0.plugin —— 歌词源插件（存量）
- SHA256SUMS.txt —— 全文件校验和

## v8.7.37 更新
1. 流畅模式三连修：掠影壁纸不再跳动、时钟冒号不再加速闪烁（循环动画正确停用而非被加速）；流畅模式开关状态实时同步，不再出现显示关闭需再点两次
2. 开启流畅模式时自动禁用辉光背景并切换到掠影；设置面板辉光选项置灰提示不可用
3. 书签页面改为滚轮切换：磁贴区域向下滚动进入书签页、向上滚动返回（常驻与抽屉两种样式生效）
4. 新增 Alt+V 快捷键开关快捷服务抽屉

## 安装
1. 解压 ChuShi-NewTab-v8.7.37.zip（或直接以 zip 形态加载）
2. Chrome 打开 chrome://extensions → 开发者模式 → 加载已解压/拖入 zip
3. 新标签页 → 设置 → 预设 → 导入 初始网易云播放器预设.cshz（老用户直接更新预设）

## 备注
- 播放器需网易云音乐接口可达；扫码登录后可看我的歌单、VIP 歌曲跟账号权限走
- 书签数据存本地（start:bookmarks），弹窗收藏/删除与新标签页书签页实时同步
