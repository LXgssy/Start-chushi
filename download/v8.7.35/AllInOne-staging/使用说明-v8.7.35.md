# 初始 · Start v8.7.35 交付说明（beta）

## 本包内容
- ChuShi-NewTab-v8.7.35.zip —— 扩展本体（本版：浮窗退散+浮窗开关+页签居中+掠影压暗+时钟日期显隐）
- ChuShi-CloudSnapshot-v8.7.35.zip —— 云端快照载荷
- 初始SMTC音乐预设.cshz —— SMTC 桥接音乐面板预设（存量）
- 初始网易云播放器预设.cshz —— 网易云 dock 弹出播放器预设（存量）
- 焕新示例预设.json —— 八维焕新示例预设（存量）
- ChuShi-Music-Bridge-8.4.0.zip —— 音乐桥插件（存量）
- ChuShi-Lyric-Source-7.3.0.plugin —— 歌词源插件（存量）
- SHA256SUMS.txt —— 全文件校验和

## v8.7.35 更新
1. 移除网易云播放器预设后，悬浮音乐卡随之消失（音频停播+真值撤除）；播放器页头新增浮窗显隐开关
2. 播放器顶部页签选中态文字居中修复（字体度量补偿退役，回归平台标准居中）
3. 掠影壁纸压暗程度可自定义：设置 → 掠影壁纸 → 压暗程度（0–200%，默认 100%）
4. 时钟与日期可分别显示/隐藏：设置 → 时钟

## 安装
1. 解压 ChuShi-NewTab-v8.7.35.zip（或直接以 zip 形态加载）
2. Chrome 打开 chrome://extensions → 开发者模式 → 加载已解压/拖入 zip
3. 新标签页 → 设置 → 预设 → 导入 初始网易云播放器预设.cshz（老用户直接更新预设）

## 备注
- 播放器需网易云音乐接口可达；扫码登录后可看我的歌单、VIP 歌曲跟账号权限走
- 音质三选一弹窗：标准 / 极高 / 无损（无损需黑胶账号，无权限自动回退并提示）
