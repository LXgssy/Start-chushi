# 初始 · ChuShi v1.1.3 更新说明

**架构纠偏：液态玻璃引擎全部移入预设包 + ⌘K 两处交互修复**

## 一、液态玻璃架构纠偏（本次核心）

此前 v1.1.0 把液态玻璃折射引擎内建进了「初始」宿主代码（`effects.glass` 声明式参数 + 宿主内建渲染引擎），与「宿主只提供 API、效果全部由预设包自带代码实现」的产品设想相悖。v1.1.3 彻底纠正：

- **删除宿主内建引擎**：移除 `liquid-glass.ts` 折射引擎、`effects.glass` 声明式支持与配套主题 CSS——宿主不再包含任何一行液态玻璃实现。
- **宿主只提供 fx 受控作用面**（新 API，预设脚本可用）：
  - `chushi.fx.mount(id, html)` / `unmount(id)`：把纯视觉结构（`<style>` / `<svg>`）幂等挂进宿主隐藏容器，同 id 重复挂载为替换；
  - `chushi.fx.onResize(cb)`：订阅玻璃容器尺寸快照（`[{fx, key, w, h, radius}]`），贴图按尺寸重生成；
  - `[data-fx="fxN"]`：宿主打在玻璃容器（搜索栏 / 底部栏 / 面板卡 / ⌘K 卡）上的稳定标记，预设 CSS 用它触达真实元素；
  - `--fx-mx` / `--fx-my`：指针在容器内移动时的相对坐标变量，预设 CSS 用 `var()` 做镜面高光。
- **液态玻璃预设包 = 完整引擎**：官方「液态玻璃预设.json」重写为自带全部实现代码的预设——canvas 生成圆角矩形 SDF 位移贴图、SVG feDisplacementMap 折射滤镜、玻璃底调透 + 边缘高光 + 镜面高光材质，全在预设包的 scripts 里；**安装即生效、删除预设即整组回收**，视觉与 v1.1.2 完全一致（模糊在前、折射在后的链序律保留：`blur(3px) url(#filter) saturate(180%)`）。
- 安全校界：mount 内容仅允许 `<style>` / `<svg>`（禁 script、事件属性、foreignObject、外链资源），单次 ≤192KB、每预设 ≤512KB；全屏幕布永不打标（幕布不是玻璃块）。
- 沙箱脚本单段代码上限 8000 → 16000 字符（给第三方视觉引擎留出空间）。

## 二、⌘K 面板交互修复

1. **「删除预设返回后点空白关不掉面板」——根治**：实证根因是 toast 通知竖带（右上角常驻 DOM，toast 显示期间 `pointer-events` 被置回 auto）在 z-100 层拦截了 ⌘K 遮罩（z-50）右侧整列的点击。修复后 viewport 自身永不接收指针（toast 卡片本体不受影响，hover 暂停 / 滑动关闭照旧）。
2. **「鼠标不在面板上也一直残留选中一个选项」——根治**：cmdk 恒有一个键盘导航锚点项带选中高光，指针离开面板后仍常驻。改为三态门控（`data-nav`）：指针在面板内→高光跟随悬停；方向键导航→高光可见（键盘可达性不回退）；指针在外且未用键盘→不显示任何选中高光。

## 三、升级说明

- 网页版：刷新即新版（部署于 GitHub Pages）。
- 扩展版：下载 `ChuShi-NewTab-v1.1.3.zip`，Edge 扩展管理页「重新加载」或移除后重装。
- **已装旧版液态玻璃预设的用户**：旧预设的 `effects.glass` 字段已不再被宿主识别（无害残留）；请删除旧预设、重新导入仓库 `examples/液态玻璃预设.json` 即可继续体验（新版为自带引擎实现）。

- 新增：`src/lib/startpage/fx.ts`（宿主 fx 作用面）、沙箱侧 `chushi.fx` API、自带引擎版液态玻璃预设
- 修复：toast viewport 拦截 ⌘K 遮罩点击；cmdk 选中高光残留门控
