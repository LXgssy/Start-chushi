## 二、WebGL 光学管线（游乐场同款物理）

- **透镜剖面** = circleMap 圆弧透镜投影 `1−√(1−t²)`（球面透镜厚度，越靠边越陡，带外平坦）；
- **折射方向** = 圆角矩形 SDF 梯度（外法线），`depthEffect` 可叠加向心分量；
- **负量内采样**：折射量取负 = 凸透镜放大（游乐场/Kyant 默认 −24dp 同向）；
- **色散** = 7 通道 ROYGBV 分层采样（权重照抄游乐场 AGSL）；底栏玻璃指示器强制开色散；
- **霜化** = Vogel 金角螺旋 16-tap 高斯盘；**边缘高光** = 独立描边 pass（Plus 加法混合，Default/Plain 两模式）；
- **背景** = 真实壁纸逐帧采样：壁纸纹理 cover 拟合 + kenburns 漂移逆变换跟随 + 压暗遮罩（photo-scrim 三段）；预乘 alpha 输出无黑边；
- **实时渲染**：rAF 逐帧几何追踪（含按压缩放/速度拉伸的 layerScale），动画变动期 30fps 节流、折射全程在线；
- **工程**：全引擎共享单一 GL 上下文 + 位图串行队列上屏（浏览器 WebGL 上下文数上限免疫）；跨域壁纸自动走 crossOrigin 链路，不可用时无缝降级 CSS 磨砂。

## 三、玻璃面板与设置：换成游乐场的

- 搜索药丸 / 底部栏 / 底栏指示器 / 面板卡片 / 全站玻璃卡（⌘K、对话框、右键菜单、开发者文档）/ 天气芯片全部由新引擎着色，角色默认参数逐项对照游乐场各页（底栏容器 lens 24/−24、指示器 lens 10/−14 + 色散、面板 lens 16/−32 + Plain 高光 0.38 等）；
- 设置面板换成**游乐场同款滑杆**：折射高度（0–48px）、折射强度（0–48px）、模糊半径（0–32px）、色散强度（0–100%）、饱和度（100–260%）、透亮（85–115%）+ 边缘高光开关 + 覆盖范围（全部玻璃面 / 基础四区），**热调即生效**；
- 新增**嵌套玻璃豁免**律：玻璃面板内部的小芯片不再误采壁纸（背景不是壁纸的面不打标）。

## 四、底部标签栏动效：换成游乐场的

- 活动指示器从 framer 背景色药丸换成**独立滑动玻璃胶囊**（引擎单独折射）；
- 滑动/按压/速度拉伸物理忠实移植 LiquidBottomTabs + DampedDragAnimation：
  - 滑动 = 临界阻尼 spring(1, 1000)；按压 = 临界阻尼 spring(1, 1000)；
  - 按压缩放 = 欠阻尼 spring(0.6/0.7, 250)，按下放大到 **78/56**，带回弹；
  - 拖拽速度拉伸：`scaleX /= 1−clamp(v×0.75)`、`scaleY ×= 1−clamp(v×0.25)`（除数 10）；
  - panelOffset = 4dp × sign × EaseOut 整行随手指微移；容器/内容按压缩放（16dp/宽 × 1.2）；
- **支持按住任意位置拖拽滑选**（LiquidBottomTabs 阻尼拖拽律：松手四舍五入吸附最近面板）。

## 五、按钮动效：换成游乐场的

- dock 按钮按压 = LiquidButton 律：scale 1+4/48×p（临界阻尼）+ tanh 拖拽平移（按下拖动按钮会跟手偏移，松手弹回）+ 追光白晕（InteractiveHighlight 的 Plus 混合等价，光斑跟随按下位置）。
