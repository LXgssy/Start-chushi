# 初始 · ChuShi v1.2.0 更新说明

**液态玻璃物理透镜重写（对齐 Apple 边缘折射）+ 设置面 API 开放 + 面板动画防闪**

## 一、液态玻璃 v2：物理透镜折射（引擎仍全在预设包里）

官方「液态玻璃预设」引擎重写，对齐 Apple 液态玻璃的边缘透镜观感：

- **折射方向改为 SDF 梯度（边缘外法线）**：长边中部的弯曲垂直于边缘，与真实透镜一致；旧版位移指向几何中心，长边上会产生斜向歪折（「不太符合物理定律」的主因）。
- **外绕环绕（wrap）**：边缘环带改为**向外取样**——环带显示的是被压缩进来的**玻璃外世界**（纸镇 / 鱼缸效应），文字与色块在玻璃边缘被弯曲拉入，而非把内部向中心抹平。为此 SVG 滤镜域（`filterUnits="userSpaceOnUse"`）外扩 pad，边缘可以取到元素边界之外的世界，pad 环上位移渐隐归零防硬边。
- **边缘窄带 + smoothstep² 剖面**：折射集中在边缘窄带（默认半短边的 26%，旧版 50%），带内越靠边越陡，观感更接近薄倒角实物玻璃；贴图半分辨率生成（梯度场平滑，视觉无损，编码成本 1/4）。
- **可选边缘色散**：三通道（R/G/B）分层位移 + 算术合成，玻璃边缘出彩虹棱边（默认关）。
- 链序律保留：`blur(3px) url(#filter) saturate(180%)`——先霜化再折射，弯曲锐利。

## 二、新 API：chushi.settings 设置面（宿主只加作用面，不加实现）

预设脚本现在可以**向设置面板贡献自己的调节项**（架构律不变：宿主提供受控作用面，实现代码全部住预设包）：

- `chushi.settings.define(schema)`：声明设置分区（标题 ≤24 字 + 1–12 个控件；`slider` / `toggle` / `select` 三类，schema 整体白名单校验）；
- `chushi.settings.get()`：启动期取值（宿主按 schema 校验 localStorage 持久化值并补默认值，脚本拿到的值永远合法）；
- `chushi.settings.onChange(cb)`：用户改动时热回调整组值，返回退订函数；
- 值持久化在 `start:preset-settings`（仅本机），**删除预设即分区与持久化值一并回收**；脚本冻结分区同步消失。

官方液态玻璃预设随即接入：设置面板新增「液态玻璃」分区，**折射强度 / 边缘带宽 / 霜化模糊 / 饱和度 / 透亮**五根滑杆 + **边缘色散 / 镜面高光**两个开关，拖动即热生效并持久化。

## 三、根治「面板开合动画期间液态玻璃闪动」

根因：`backdrop-filter: url(#svg)` 的位移滤镜在元素**布局尺寸连续变化**（dock 面板高度弹簧、窗口拖拽缩放）时逐帧重栅格化，且位移贴图尺寸滞后错帧——表现为闪动。修复律（已写进引擎与文档）：尺寸变动期退化为纯 `blur/saturate`（标准滤镜函数无此病），尺寸稳定约 160ms 后再生成贴图换全链。

## 四、其他

- **导入预设支持拖拽**：把 `.json` / `.cshz` / `.zip` 预设文件直接拖进「导入预设」面板即安装；拖入时输入框高亮提示；拖到面板外不再触发浏览器「打开文件」。
- **子元素模糊过场全覆盖**：右键菜单的菜单项、开发者文档的分区，打开/关闭均有级联模糊聚拢/散场（与全 app「内容模糊语言」同源，尊重 `prefers-reduced-motion`）。
- **整页焕新能力评估**（§15 新增）：材质、内容、排版、动画四个维度已可经预设系统整页焕新；图标替换与主题令牌覆写列为下一批最值得补的作用面（详见开发者文档）。
- 回收卫生：全部 fx 预设删除后 `data-fx` 标记与指针变量一并擦净，删除即还原语义更完整。

## 升级说明

- 网页版：刷新即新版（GitHub Pages）。
- 扩展版：下载 `ChuShi-NewTab-v1.2.0.zip`，Edge 扩展管理页「重新加载」或移除后重装。
- 已装旧版液态玻璃预设的用户：请删除旧预设后重新导入本包内 `液态玻璃预设.json`（旧引擎无设置面板与防闪策略）。
