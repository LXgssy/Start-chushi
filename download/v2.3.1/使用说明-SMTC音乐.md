# 「初始」SMTC 音乐 · v2.3.1 使用说明

> v2.3.1 是针对你最新真机反馈的四联修复：
> **弹窗根除 · 进度/歌词/时间冻死 0:00 根治 · 播放态反转根治 · 按钮位移根治**。

---

## 一、你遇到的三个问题，分别是什么原因

### 1. 那个「Windows Script Host」弹窗（0x80070312）
这是 **你电脑上的策略/安全软件拦截了「wscript 拉起 powershell」的进程创建**。
v2.3.0 的插件监督每 20 秒重试一次拉起，每次被拦截都弹一个模态框，所以反复弹。
v2.3.1 四层根治：
- VBS 启动器加 `On Error Resume Next`——**任何失败都静默，物理上不可能再弹窗**
- 插件改为**直接启动 powershell**（不经 wscript，少一层会被拦的进程链）
- 部署文件**读回校验**：内容正确才拉起（你机器上报「第 17 行」说明旧部署曾被
  写坏过——v2.3.1 宁可不启动也绝不运行损坏脚本）
- 拉起失败按 **20/40/80/120 秒退避**，不再每 20 秒硬重试

### 2. 进度条/逐字歌词冻死、播放时间显示 0（本轮最大 bug，我修的）
v2.3.0 插件里「挑哪个音频元素读进度」的逻辑选错了对象：网易云页面里不止一个
媒体元素（预加载的下一首、残留的 video 等），选中错误的元素后把「暂停 + 0 秒」
当成真值上报，面板就被钉死在 0:00——歌词和时间自然全部冻住。
v2.3.1 **真值熔断重构**：
- 改用 **网易云自家播放引擎的原生事件**（PlayState/PlayProgress）作为播放态和
  进度的主源——它不可能被错误元素污染
- 媒体元素降级为「对齐校验」：与原生进度相差超过 1.5 秒的元素一律不采信
- 再加垃圾零值熔断：位置很深时突然报 ≈0 且 5 秒内没有拖动 → 直接丢弃该样本
- 宿主侧再加两击守卫：单个「暂停+0」样本不再被采纳（双保险）

### 3. 「初始」和网易云播放状态反着来（概率性）
就是问题 2 的另一面：选中了错误的元素，它的「是否在播」和真相反着来。
真值熔断后，面板读的就是网易云自己引擎的状态，**结构上不可能再反**。

### 4. 播放/暂停按钮位移
面板高度会随「歌词出现/消失」反复变化（每次塌 124px），把按钮上下推动。
v2.3.1 歌词高度迟滞：**同一首歌里歌词暂时消失（桥重启/重拉）面板高度不再变化**，
只有切歌才重算高度。

## 二、升级步骤（三件套）

1. **网页版** Ctrl+F5 强刷；**扩展版**重装 `ChuShi-NewTab-v2.3.1.zip`
2. **网易云**：把 `初始歌词源-1.4.0.plugin` 放进 BetterNCM 的 plugins 文件夹
   （**删掉旧版 1.3.0 及更早**）→ 重启网易云 → 放首歌
3. ⌘K → 预设 → 删除旧「初始 · SMTC 音乐」→ 导入新的 `初始SMTC音乐预设.cshz`

## 三、自检清单（2 分钟）

1. 放歌 → 进度条前进、逐字歌词扫色、时间不再是 0:00
2. 页脚显示 `已连接 · 网易云音乐 · 插件 v1.4.0`
3. **不再出现任何 Windows Script Host 弹窗**（若仍有，截图发我——那说明有
   第三方软件在别处拉起旧文件，交付包里有手动启动方案，见下）
4. 面板顶部没有橙色「组件过旧」芯片（有 = 插件没换到 1.4.0）
5. 暂停 5 秒再继续 → 歌词严丝合缝；拖动进度条 → 看网易云本体是否跟着跳

## 四、手动启动桥（备用方案，一般用不到）

如果你的机器连插件直启 powershell 都被策略拦截（面板一直「未连接」），
交付包里的 `手动启动桥（备用）` 文件夹可以救急：
1. 把整个文件夹**解压到任意固定位置**（别放临时目录）
2. 双击 `启动SMTC桥.bat`——出现窗口属正常（手动模式没有隐藏通道），
   最小化即可，**不要关**
3. 重启网易云，面板恢复后可以把 bat 窗口关掉交给插件接管

## 五、常见问题

- **旧弹窗怎么彻底消失？** 弹窗由旧版部署的 VBS 触发；装 1.4.0 插件重启网易云后，
  新插件会接管桥并部署静默版 VBS，弹窗源自动消失。
- **想看诊断？** 网易云按 F12 → Console 过滤 `[ChuShiLyricSource]`，有
  部署/读回校验/拉起/退避/seek 生效的完整日志。
- **防误解**：Windows 不允许浏览器页面直接读系统媒体状态，那个看不见的本机
  小进程在物理上必须存在——它仍由插件全自动管理，你只面对一个 .plugin。
