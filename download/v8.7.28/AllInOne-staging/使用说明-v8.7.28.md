# 初始 · Start v8.7.28 交付说明（beta）

## 本包内容
- ChuShi-NewTab-v8.7.28.zip —— 扩展本体（本版：网易云播放器整页重写）
- ChuShi-CloudSnapshot-v8.7.28.zip —— 云端快照载荷

- 初始网易云播放器预设.cshz —— 网易云直链播放器预设（本版整页重写同步内置）

## 安装（升级）
1. 解压 ChuShi-NewTab-v8.7.28.zip → chrome://extensions → 开发者模式 → 「加载已解压」指向解压目录
   （老用户：删旧目录重解压 = 全新安装，无增量权限审批）
2. 已装网易云播放器预设的用户：预设本体随扩展内置更新，无需重装

  搜索结果以「搜索」视图呈现、不占页签（视图切换时两枚页签同时熄灭），
  世代令牌 + 关键词双对账防串扰（连发搜索慢者不覆盖快者、切走视图迟到回包即弃）

  重实现并经基准库矩阵逐格交叉验证），全部能力保留——扫码登录 / 每日推荐 /
  我的歌单两级 / 逐字歌词 / 音质三选一弹窗 / 频谱律动 / 全局歌词互通 / 退出登录
