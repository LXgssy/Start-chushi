# 「初始」SMTC 音乐面板 · 使用说明（v2.0.1）

> 本轮（v2.0.1）修复：暂停后进度/歌词归零、再播放从头计数、进度条拖不动/拖完弹回、
> 播放/暂停按钮反应慢、打开面板闪白、歌词逐字扫色闪动、关闭箭头方向反了、
> 音乐面板↔其它面板的切换动画（现在是同一套拉伸+模糊，不再是两段式开/关）。

## 一、升级三步（从 v2.0.0 及更早版本）

1. **换桥**：关掉旧的桥窗口 → 解压本包 → 双击新包里的「启动SMTC桥.bat」。
   （窗口标题显示 v1.4.0 即为新版；建议重新运行一次「添加开机自启.bat」指向新文件位置。）
2. **换预设**：「初始」页面 → ⌘K → 预设 → 删除旧的「初始 · SMTC 音乐」→ 导入本包里的
   `初始SMTC音乐预设.cshz`（新预设带新样式：向下关闭箭头、逐字扫色不闪动、拖动预览跟手）。
3. **刷新网页**：网页版按 **Ctrl+F5**（Service Worker 会先发旧缓存，硬刷新一次才切到 v2.0.1）；
   扩展版请重新安装 `ChuShi-NewTab-v2.0.1.zip`。

> 即便暂时不升级桥（仍用 v1.3.0），网页 v2.0.1 也已在宿主侧做了守卫：
> 暂停归零/恢复从头/拖动弹回这三类旧桥伪影都会被兜住。但推荐一并升级桥，源头数据更干净。

## 二、日常使用

- 点 dock 栏最右侧的 **音乐按钮** 弹出音乐面板；再点一次 / 点收起键（右上角 **向下箭头**）/
  按 Esc / 点面板外空白，均可收起。
- 面板内容自上而下：封面（播放中带呼吸光晕）→ 歌名/歌手/专辑 → **进度条**（可直接
  按住拖动，松手即跳转）→ 上一首 / 播放暂停 / 下一首 → **逐字歌词**（当前词扫色高亮，
  下方附翻译）→ 连接状态。
- 天气/待办/便签/番茄钟/设置面板与音乐面板互切时走同一套「拉伸 + 模糊聚拢」动画。

## 三、逐字歌词（可选组件）

逐字歌词数据来自网易云客户端内的「初始歌词源」插件（本包内 `初始歌词源-1.0.0.plugin`）：

1. 前提：已安装 BetterNCM（Chrome 内核版网易云）。
2. 把 `.plugin` 文件放进 `C:\betterncm\plugins\`，重启网易云。
3. 插件自动向桥推送当前曲歌词与精确进度；没有插件时歌词区不显示，其余功能不受影响。

## 四、常见问题

- **面板显示「系统媒体待接入」**：桥没在跑。双击「启动SMTC桥.bat」，保持窗口开着。
- **点歌没反应 / 面板一直空**：先在网易云里放一首歌；SMTC 会话由播放器注册，「初始」只读取。
- **进度条拖了没反应**：确认窗口标题是 v1.4.0 桥；旧版桥在网易云不刷新时间轴时会拖不动。
- **歌词没出现**：确认装了歌词源插件且曲目有逐字/行级歌词；纯音乐无歌词属正常。
- **网页还是旧版**：Service Worker 缓存——再开一次新标签页或 Ctrl+F5。
- **开机自启**：双击「添加开机自启.bat」（写入用户启动项，不碰注册表）。
