# 「初始 · Start-chushi」v1.7.5 更新说明

> 发布日期：2026-09-04　|　网页版：https://lxgssy.github.io/Start-chushi/　|　仓库：https://github.com/LXgssy/Start-chushi

本批为**网易云音乐接入批**：初始新增「音乐」面板——在网易云装上 chromatic（BetterNCMII）插件管理器与本批配套的「初始音乐桥」插件后，初始能实时显示正在播放的歌曲并遥控播放。

---

## ① 新增「音乐」面板（Dock 新按钮 + ⌘K 入口）

Dock 在番茄钟与指令面板之间新增「音乐」按钮（可被预设图标作用面覆写），面板三态：

- **未接入**：三步接入指引 + 服务地址修正 + 重试；
- **已连接**：封面（网易云 CDN 直链，已升 https）+ 歌名/歌手 + 可拖拽进度条（点击/拖动即 seek）+ 播放/暂停/上一首/下一首 + 音量条；
- **空态**：已连接但未在播放。

进度条采用**本地时钟插值**：桥每秒推一帧快照（含写入时间戳），面板在两帧之间按本地时间外推，指针平滑前进，不受轮询节奏抖动影响；连接断开自动回落到指引态并低频探测恢复。

## ② 「初始音乐桥」插件（新交付物）

配套发布了网易云侧插件 `ChuShi-Music-Bridge-v1.0.0.zip`，双组件架构：

- **index.js**（渲染进程注入）：经 webpack require 拿到网易云 3.x 的 dva Redux store，订阅原生播放事件（PlayState/PlayProgress/Seek），把播放快照（歌名/歌手/专辑/封面/时长/进度/音量/播放态）原子写入 BetterNCM 数据目录 `chushi-music\state.json`；同时监听命令目录，把「初始」发来的控制命令 dispatch 给网易云（`playing/resume`、`playing/pause`、`playingList/jump2Track`、`playing/setPlayingPosition`、`playing/setVolume` 等）。取不到 store 时自动降级为只读模式（`betterncm.ncm.getPlayingSong()` + 媒体元素轮询）。
- **bridge.dll**（原生插件，`native_plugin` 机制加载）：在网易云进程内启动**仅绑定 127.0.0.1** 的本地 HTTP 服务（默认 10754，冲突自动顺延并写入 `server.json`），提供 `GET /api/ping`、`GET /api/status`、`POST /api/control`。Origin 白名单只放行浏览器扩展与初始线上域/本机地址——其他网站的跨源请求不回 CORS 头，防止任意网页窥探正在播放的内容。

**为什么需要一个 DLL**：网易云桌面端是 CEF 架构，渲染进程没有 Node、插件 JS 无法直接监听端口；BetterNCMII 的原生插件机制（与 InfLink 的 backend.dll 同路数）是官方给插件的本机能力通道。JS 与 DLL 之间以数据目录文件为契约，互不感知进程边界；DLL 在主进程/渲染进程重复加载时用命名互斥体保证服务单例。

## ③ 安装（三步）

1. 在网易云音乐安装 **chromatic** 插件管理器（https://github.com/std-microblock/chromatic）；
2. 解压 `ChuShi-Music-Bridge-v1.0.0.zip`，把文件夹放入 `C:\betterncm\plugins_dev\`（或拖入插件管理界面安装）；
3. 重启网易云音乐，打开初始 → Dock「音乐」→ 自动连接（网页版首次连接浏览器可能询问「允许访问本地网络」，允许即可；扩展版无需此步）。

- **网页版**：刷新页面即自动换装（Service Worker 后台静默更新）。

## 已知限制

- 歌词显示、红心收藏、播放队列展示暂未包含（后续版本按需追加）；
- 网易云 2.x 旧客户端未适配（插件面向 3.x 的 dva store）；
- 网页版连接依赖浏览器的本地网络访问策略（Chrome/Edge 138+ 会弹权限询问，旧版浏览器可能直接拦截——扩展版无此问题，推荐扩展版使用）。
