# 「初始」× SMTC 系统媒体 —— 全新音乐接入（v1.8.2）

> 从 v1.8.0 起，「初始」的音乐接入**整体换线**：不再需要任何网易云音乐插件
> （BetterNCM 插件 / 旧 CDP 独立桥全部退役），改为直连 **Windows 系统媒体会话
> （SMTC）**——网易云音乐、QQ 音乐、Spotify、浏览器视频等任何在 Windows 里
> 正在播放的内容，「初始」都能看见、都能控制。
>
> **v1.8.2 更新**：① 音乐面板**移进底部 dock 栏**——不再占角落磁贴，安装预设后
> dock 栏出现「音乐」按钮，点击在 dock 上方**弹出音乐面板**（弹出/收起都有与
> 内建面板一致的弹簧动画）；② 修复启动器 .bat 乱码第二轮：改为**纯 ASCII + CRLF**
> 发布，任何编码环境的 cmd 都不可能再出假命令（窗口提示为英文，属正常现象）；
> ③ 修复音乐部件空态的两处视觉缺陷（顶部白条 / 文案叠加）。

## 这条路线的原理

Windows 10/11 的系统媒体浮层（按媒体键弹出的那个小卡片）背后是 SMTC 机制，
每个播放器都会把自己的「歌名 / 歌手 / 封面 / 播放进度」上报给系统。
「初始」不再钻进网易云内部，而是从**系统层面**读取这套会话：

```
网易云音乐 ──上报──▶ Windows SMTC（系统媒体会话）
                          │
              初始SMTC桥（本机 PowerShell，零依赖）
                          │  http://127.0.0.1:20754
                          ▼
              「初始」新标签页 · dock「音乐」按钮 → 弹出音乐面板
```

好处：**不侵入网易云**（升级网易云永远不受影响）、**不挑播放器**（换什么音乐
软件都能用）、**零安装**（桥就是一个双击运行的脚本文件）。

## 使用步骤（两步）

### 第 1 步：启动「初始SMTC桥」

1. 解压交付包，得到 `初始SMTC桥` 文件夹
   （内含 `ChuShi-SMTC-Bridge.ps1` 与若干 .bat）；
2. 双击 **`启动SMTC桥.bat`** —— 弹出一个控制台窗口显示监听信息（英文），
   **保持它开着**；
3. （推荐）双击 **`添加开机自启.bat`** —— 以后开机登录即自动后台运行，无需再管。

> 桥只监听本机回环地址（127.0.0.1:20754），不对外网开放；关闭窗口 = 停止。
> 若提示端口被占用，说明已有一个桥在运行，直接用即可。
> 原有的 BetterNCM 插件 / 旧音乐桥请从网易云和电脑里移除，避免干扰。
> v1.8.2 的 .bat 内容是纯 ASCII（英文提示）+ CRLF 换行——这是**故意的**：
> v1.8.0（UTF-8）与 v1.8.1（GBK + Unix 换行）两版在中文 Windows 上先后触发了
> 两种 cmd 解析怪癖（乱码假命令），纯 ASCII 从根上杜绝，请勿另存为其他编码。

### 第 2 步：在「初始」里安装音乐预设包（.cshz）

1. 打开「初始」新标签页，按 `⌘K`（或 `Ctrl+K`）→ **导入预设**；
2. 选择交付包里的 **`初始SMTC音乐预设.cshz`** → 安装
   （.cshz 是「初始」的预设包格式：UI、样式、默认封面资源全部打包在内，
   导入后无需保留该文件）；
3. 底部 dock 栏立即出现 **「音乐」按钮**：网易云一放歌，点它弹出音乐面板，
   封面 / 歌名 / 进度就亮起来。

## dock 音乐面板交互

| 动作 | 效果 |
| --- | --- |
| 点击 dock「音乐」按钮 | 弹出 / 收起音乐面板（弹簧弹出动画） |
| 面板外的页面任意处点击 / 按 Esc | 收起面板 |
| 点击播放/暂停大按钮 | 播放 ⏯ |
| 拖动进度条 | 快进 / 快退（松手生效） |
| ⏮ / ⏭ | 上一首 / 下一首 |
| 面板右上角 ⌃ | 收起面板（等同再点 dock 按钮） |
| 底部状态行 | 实时显示「已连接 · 来源应用」 |
| 没有媒体会话时 | 面板显示 92px 引导态，放歌后自动长成 248px 大卡 |

⌘K 指令面板同时新增四条命令：**音乐：播放/暂停、下一首、上一首、正在播放什么**。

## 常见问题

**Q：双击 .bat 还是闪退/乱码/报假命令？**
确认用的是 v1.8.2 交付包。v1.8.0（UTF-8 编码）与 v1.8.1（GBK 编码但 Unix 换行）
在中文 Windows 的 cmd 下会分别出现 `'敤'`/`'垵濮?SMTC'` 与 `'ANSI'`/`'桥'`/`'MTC'`
一类的乱码假命令。v1.8.2 改为纯 ASCII 内容 + Windows 标准 CRLF 换行，
不再依赖任何编码假设。窗口提示是英文属正常现象。

**Q：面板显示「系统媒体待接入」？**
桥没在运行。双击 `启动SMTC桥.bat`，或运行 `添加开机自启.bat` 后注销重新登录。

**Q：显示「等待媒体会话」？**
桥正常，但系统里还没有播放器在放歌。打开网易云音乐放一首歌即可。

**Q：控制点了没反应？**
部分应用（如个别网页视频）不开放控制权限——SMTC 的控制权由播放器自己决定，
网易云桌面版全支持（播放/暂停/上下曲/进度）。

**Q：想控制别的播放器？**
不用配置。桥默认优先跟随网易云，网易云没在放时自动跟随「正在播放」的那个应用。

**Q：卸载？**
「初始」里删除预设即移除 dock「音乐」按钮与命令；运行 `移除开机自启.bat`
并关掉桥窗口即完成清理。
