# 初始 · Start v8.7.42 交付说明（beta）

## 本包内容
- ChuShi-NewTab-v8.7.42.zip —— 扩展本体（本版：预设系统全面开放·掠影深色灰字提亮）
- ChuShi-CloudSnapshot-v8.7.42.zip —— 云端快照载荷
- 初始SMTC音乐预设.cshz —— SMTC 桥接音乐面板预设（存量）
- 初始网易云播放器预设.cshz —— 网易云 dock 弹出播放器预设（存量）
- 焕新示例预设.json —— 八维焕新示例预设（存量）
- ChuShi-Music-Bridge-8.4.0.zip —— 音乐桥插件（存量）
- ChuShi-Lyric-Source-7.3.0.plugin —— 歌词源插件（存量）
- SHA256SUMS.txt —— 全文件校验和

## v8.7.42 更新
1. 掠影模式+深色模式下，所有面板里的灰色文字整体提亮一档，深色面板底色同步加深，可读性明显回升
2. 预设系统全面开放：导入不再受 2 万~4 万字符限制，页面/小部件/脚本/样式全部放开到 MB 级（整包上限 8MB）
3. 预设可声明网络 API（api 字段）：导入时浏览器原生弹窗逐域授权，扩展后台代理请求（绕过跨域限制），管理列表里可随时用地球按钮撤销授权
4. 基础安全审核保留：无效字符/孤立代理对/静态死循环/语法错误在导入时直接拦截；死循环常驻写法（含 await）放行并由沙箱心跳兜底——无响应时自动重启沙箱，主页永不卡死
5. 沙箱新增 chushi.proxyFetch(url, init) 受控 API 供预设调用；开发者文档与示例同步

## 安装
1. 解压 ChuShi-NewTab-v8.7.42.zip（或直接以 zip 形态加载）
2. Chrome 打开 chrome://extensions → 开发者模式 → 加载已解压/拖入 zip

## 备注
- 带网络 API 声明的预设导入时会出现浏览器原生权限弹窗，授权粒度=域；可在浏览器扩展详情页撤销
- 沙箱脚本仍拿不到页面数据与扩展 API；声明的域由后台逐条复核授权状态
- 掠影+深色灰字优化对浅色主题零影响；流畅模式动画保留方针不变
