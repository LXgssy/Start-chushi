# 初始 · Start v8.7.27 交付说明（beta）

## 本包内容
- ChuShi-NewTab-v8.7.27.zip —— 扩展本体（本版：网易云播放器重写为命令面板式弹窗）
- ChuShi-CloudSnapshot-v8.7.27.zip —— 云端快照载荷
- 初始SMTC音乐预设.cshz —— SMTC 桥接音乐面板预设（存量）
- 初始网易云播放器预设.cshz —— 网易云直链播放器预设（本版整体重写同步内置）
- 焕新示例预设.json —— 页面焕新预设（存量）
- ChuShi-Music-Bridge-8.4.0.zip —— SMTC 桥（沿用 8.4.0，无需更新）
- ChuShi-Lyric-Source-7.3.0.plugin —— 歌词源插件（沿用）

## 安装（升级）
1. 解压 ChuShi-NewTab-v8.7.27.zip → chrome://extensions → 开发者模式 → 「加载已解压」指向解压目录
   （老用户：删旧目录重解压 = 全新安装，无增量权限审批）
2. 已装网易云播放器预设的用户：⌘K → 官方预设 → 重新安装「网易云播放器预设」即得新版
   （或删旧 preset 重装；重装后窗口尺寸 560×540 与新版弹窗形态才生效）

## 本版四项迭代（网易云播放器）
- 播放器整体重写为命令面板式居中弹窗：雾化遮罩 + 居中玻璃卡 + Q 弹入场（⌘K 同语言），
  不再从 dock 上方弹出；iframe 常驻预热，开合零重载，状态跨开合保留；窗口 560×540
- 音质切换改为三选一小弹窗（标准 128K / 极高 320K / 无损 FLAC·黑胶）：点音质按钮弹出，
  对勾跟随当前档，点选项/点外部/Esc 收起；播放中切换自动续接进度
- 修复：切换音质后封面与歌词消失（封面显隐守卫收窄 + 歌词引擎 rAF 韧性续跑，双根修）
- 修复：打开过每日推荐后再开搜索，搜索页出现每日推荐（页签世代令牌 + 列表来源对账，
  异步慢接口迟到回包也不再串页）；搜索行常驻化（任意页签回车直达搜索）+ 我的歌单双列卡片
