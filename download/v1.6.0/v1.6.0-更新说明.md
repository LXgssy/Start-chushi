# 「初始」v1.6.0 更新说明 —— 玻璃游乐场完整移植（整个 liquid-glass-webgl 仓库体系）

> 移植来源：https://github.com/martin65536/liquid-glass-webgl （「玻璃游乐场」，**作者 martin65536**，Apache-2.0）
> 原型：https://github.com/Kyant0/AndroidLiquidGlass （**作者 Kyant0**，Apache-2.0）
> 全部移植文件头部保留两份作者与出处声明。

本轮针对上一版（v1.5.0）实测截图反馈的问题逐项重构，**移植范围 = 整个 liquid-glass-webgl 仓库的组件与动效体系；只有「玻璃参数设置」取自游乐场的设置面板**（并按需求去掉「圆角半径」一项）。

## 一、玻璃设置：玻璃游乐场设置面板全量移植

上一版发布包误带旧参数（折射强度/边缘带宽/霜化模糊…），本轮换上游乐场 Glass Playground 除「圆角半径」外的**全部控件**：

| 游乐场控件 | 「初始」设置项 | 范围 |
| --- | --- | --- |
| Blur radius | 模糊半径 | 0–32px（默认 8） |
| Refraction height | 折射高度 | 0–48px（默认 24） |
| Refraction amount | 折射量 | 0–48px（默认 24） |
| Chromatic aberration | 色差 | 0–100%（默认 0） |
| （应用特有） | 覆盖范围 | 全部玻璃面 / 基础四区 |

设置即改即生效（`chushi.glass.patch` 热调）。

## 二、「不渲染组件只渲染背景」根治

玻璃身后有搜索条/磁贴/面板时，上一版只显示壁纸折射、组件被整体抹除。本轮把叠层画布改为**只画边缘折射带**（circleMap 剖面本就边缘集中，内部位移≈0，画内部纯属抹组件）：带内界位移自然归零处与玻璃体的 CSS backdrop-filter 磨砂交接，壁纸天文对齐无鬼影——**玻璃身后的 DOM 组件从此可见可点**。表面色逐角色按游乐场取值（容器/面板 0.4 透面、搜索 0.3、指示器与芯片全透明）。

## 三、底部标签栏动效补完

- **长按拖拽时指示器胶囊同步放大**（78/56 + 速度拉伸），不再「只有图标变大而边框不变」；
- 指示器**常显**（游乐场「选中项恒有胶囊」律），面板没开也有玻璃胶囊；
- **「松手概率不回弹」根治**：根因是鼠标拖出底栏外松手收不到 pointerup，拖拽状态永久卡死；修复 = 拖拽启动时刻 setPointerCapture（顺带发现并规避了 capture 挂在 pointerdown 会令底栏全部点击失效的坑——实测实录）；
- 按住任意 tab：容器/内容/指示器同步胀（DampedDragAnimation hold 律）；
- **双重放大纠正**：tab 按钮不再叠自身缩放，组按压 1.2× 内容缩放独占。

## 四、按钮动效覆盖全部 + 模式门控

- 动作按钮（⌘K / 预设 / 面板关闭 / 搜索 / 磁贴等全部按钮）改由**全局按压控制器**接管（事件委托，预设动态插入的按钮同样生效）：scale 1+4/48×p + tanh 拖拽平移 + 追光白晕；
- **「不在液态玻璃模式下不要用这套新动效」**：新增引擎订阅驱动的 `lgOn` 总开关——玻璃开启全套游乐场动效；玻璃关闭（未装/删除预设）自动恢复**原版 framer 活动药丸 + 纯 hover 过渡**，零新动效残留；
- 修复高光 pass 加法混合输出常数 alpha=1、把玻璃内部顶回不透明黑的渲染缺陷。
