# 「初始」× SMTC 系统媒体 —— 音乐面板 v1.9.0（逐字歌词版）

> **v1.9.0 更新**：① 音乐面板新增**逐字歌词（卡拉 OK 式逐词扫色）**——由全新
> 的「初始歌词源」BetterNCM 插件从网易云音乐内部读取逐字歌词（yrc），与 SMTC
> 时间戳对齐；② **封面三重保障**：SMTC 封面 → 网易云封面 URL → 默认唱片，哪层
> 都不落空；③ **进度条根治**：修复 seek 后进度条弹回的宿主缺陷（v1.8.x「进度条
> 完全是坏的」的根因），网易云 SMTC 时间轴缺失时自动用插件帧级进度兜底；④
> **面板弹出重构**：面板随页面预热，打开零白屏、零重载，弹出动画与内建面板
> 完全同一套弹簧语言；⑤ 歌词区带当前行翻译显示（有翻译数据时）。

## 这条路线的原理

Windows 10/11 的系统媒体浮层（按媒体键弹出的那个小卡片）背后是 SMTC 机制，
每个播放器都会把自己的「歌名 / 歌手 / 封面 / 播放进度」上报给系统。
「初始」从**系统层面**读取这套会话；歌词这类 SMTC 不提供的数据，则由运行在
网易云音乐内部的「初始歌词源」插件读取后经 SMTC 桥转交：

```
网易云音乐 ──上报──▶ Windows SMTC（系统媒体会话）
     │                    │
     │          初始SMTC桥（本机 PowerShell，零依赖）
     │                    │  http://127.0.0.1:20754
     │                    ▼
     │        「初始」新标签页 · dock「音乐」按钮 → 弹出音乐面板
     │                    ▲
     └── 初始歌词源插件 ──┘
         （BetterNCM 插件：逐字歌词 yrc + 帧级精确进度 + 封面 URL）
```

- **不装歌词源插件也能用**：面板的控制、进度、封面照常（歌词功能不可用，
  其余不受影响）；
- **装了歌词源插件**：解锁逐字歌词、翻译显示，网易云的进度与封面更精确。

## 使用步骤

### 第 1 步：启动「初始SMTC桥」（必须）

1. 解压交付包，得到 `初始SMTC桥` 文件夹
   （内含 `ChuShi-SMTC-Bridge.ps1` 与若干 .bat）；
2. 双击 **`启动SMTC桥.bat`** —— 弹出一个控制台窗口显示监听信息（英文），
   **保持它开着**；
3. （推荐）双击 **`添加开机自启.bat`** —— 以后开机登录即自动后台运行。
   （对应 `移除开机自启.bat` 可随时撤销。）

> 窗口提示文字是英文、内容为纯 ASCII——这是三次乱码事故后的最终形态，
> 任何代码页的 cmd 都不会再出「假命令」。中文说明以本文件为准。

### 第 2 步（可选，解锁逐字歌词）：安装「初始歌词源」插件

前提：网易云音乐已安装 **BetterNCM**（或 BetterNCMII）插件框架。

1. 把交付包内的 **`初始歌词源-1.0.0.plugin`** 放进 BetterNCM 数据目录的
   `plugins` 文件夹（与其它 .plugin 插件同一位置；框架会自动解压）；
2. **重启网易云音乐**；
3. 验证：网易云「设置 → 插件管理」里出现「初始歌词源」，且网易云内放歌时，
   面板出现歌词即成功。

> 插件端口默认 `20754`（与 SMTC 桥一致）。若你修改过桥的端口，在网易云
> 「插件管理 → 初始歌词源 → 配置」里把端口改成一致后重启网易云。
>
> 逐字歌词数据来源为网易云官方接口（eapi song/lyric/v1），仅在本机与网易云
> 之间传输，不经过任何第三方服务器。

### 第 3 步：导入音乐预设

「初始」页面按 `Ctrl/⌘ + K` → 「导入预设」→ 选择交付包内的
**`初始SMTC音乐预设.cshz`**。

> 如果你装过旧版（v1.8.2 及以前）的音乐预设，请先在 ⌘K → 预设管理里
> **删除旧预设再导入新包**（新包的歌词功能依赖新部件代码）。

## 面板功能

| 操作 | 方式 |
| --- | --- |
| 打开面板 | 点击 dock 栏「音乐」按钮（弹出动画与内建面板同款弹簧） |
| 关闭面板 | 再点一次按钮 / 点击面板外任意处 / `Esc` / 面板右上收起键 |
| 播放 / 暂停 | 面板中央大按钮 |
| 上 / 下一首 | 面板两侧按钮 |
| 调整进度 | 按住进度条拖动，松手即跳转（立即生效，不再回弹） |
| 歌词 | 有逐字数据时逐词扫色（卡拉 OK），无则行级高亮；当前行下方显示翻译 |
| ⌘K 命令 | 「音乐：播放/暂停」「下一首」「上一首」「打开音乐面板」 |

## 常见问题

- **面板显示「系统媒体待接入」**：SMTC 桥没启动——回到第 1 步；
- **显示「等待媒体会话」**：桥在线但没检测到播放器——在网易云里放一首歌；
- **没有歌词**：检查第 2 步（歌词源插件是否安装并重启网易云）；纯音乐/无歌词
  曲目不显示歌词区，面板自动收窄；
- **没有封面**：SMTC 封面与网易云封面都拿不到时显示默认唱片（极少见）；
- **更新后没有新功能**：`Ctrl+F5` 强制刷新（Service Worker 缓存旧页面），或
  重开标签页；旧预设需删除重导。
