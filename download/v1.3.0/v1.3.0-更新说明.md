# 初始 · ChuShi v1.3.0 更新说明

**液态玻璃引擎内建宿主：实时渲染 + 真环绕折射 + 覆盖范围扩容，预设包一句调用**

## 一、架构定稿：引擎写进「初始」，预设包只调用

前两版（v1.1.3–v1.2.0）把液态玻璃引擎全部代码放在预设包脚本里跑，受沙箱环境三重限制：沙箱 iframe 是 `display:none` 隐藏文档，Chromium 对隐藏文档**暂停渲染循环（rAF 永不触发）**；每次几何变化都要消息桥往返；贴图只能事后重建，布局动画期间只能退化纯磨砂——这就是「玻璃不会实时渲染」的根源。

v1.3.0 按产品决策把引擎**收编内建于宿主**（`liquid-glass.ts`）：引擎在可见文档中以 rAF 逐帧追踪玻璃几何，预设包经新 API `chushi.glass.enable / patch / disable` 一句调用，官方「液态玻璃」预设瘦身到 1.8KB（注册设置面板八项调节 + 调用引擎）。

## 二、实时渲染：动画期间折射全程在线

- **逐帧几何追踪**：rAF 循环每帧读取玻璃元素实测盒（getBoundingClientRect），transform 弹簧、高度弹簧、CSS transition 全覆盖；
- **变动期贴图实时重建**：几何变化期间以 1/4 分辨率按 ~30fps 连续重建位移贴图（折射不缺席）；几何稳定约 160ms 后自动换半分辨率精贴图；
- **无空窗帧**：新贴图经 Image 预解码、就绪后原子替换 feImage href，旧贴图保持显示——旧版「退化纯模糊再弹回」的闪动路径已彻底移除；
- 实测（Playwright 探针）：面板高度弹簧 ~900ms 内贴图重建 6 版，0 掉链帧；v1.2.0 同场景为 0 版 + 整段纯磨砂。

## 三、真环绕折射：边缘折进玻璃外的真实世界

物理层新发现：`backdrop-filter` 的取样输入被裁剪在元素 border-box 内——旧版只外扩 SVG 滤镜域，边缘环带拿到的仍是边缘像素拉伸（假环绕）。v1.3.0 对基础四区改用**边框外扩法**：

- `border: var(--lg-pad) solid transparent` + 负 margin 回拉布局 + 宽度补偿（`--lg-ww/--lg-ow` 引擎逐帧回写）：border-box 外扩 pad 而内容盒与绝对定位子元素纹丝不动；
- backdrop 取样域随之扩到**玻璃足迹之外**——边缘环带折进的是玻璃外的真实世界（Apple 纸镇/鱼缸效应），pad 环位移渐隐防硬边；
- overflow 裁剪仍在 padding-box（原玻璃边界），子元素溢出视觉不变；阴影 spread 同步回拉，影不外溢。

## 四、覆盖范围扩容

- 新增 `.glass-chip`（天气面板玻璃芯片）纳入折射（full 模式）；
- 新增设置项**「覆盖范围」**（分段选择）：`全部玻璃面`（默认，基础四区 + 芯片）/ `基础四区`（搜索栏 / 底部栏 / 面板卡片 / 全站玻璃卡）；
- 全屏幕布（⌘K / 对话框遮罩）依旧永不折射——幕布不是玻璃块。

## 五、API 与文档

- 新增沙箱 API：`chushi.glass.enable(cfg)`（单持有者制）/ `patch(cfg)` / `disable()`；cfg 八字段白名单夹紧（refraction / band / frost / saturation / brightness / dispersion / specular / coverage）；
- `chushi.fx` 保留为**通用自定义视觉作用面**（挂 style/svg、订阅玻璃容器快照），与内建引擎互不干扰；`[data-fx]` 标记清单同步新增 `.glass-chip`；
- 「液态玻璃」设置分区第八项「覆盖范围」上线；README、docs/PRESET_DEV.md、页内开发者文档（§08 重写）全部同步。

## 升级说明

- 网页版：刷新即新版（GitHub Pages）。
- 扩展版：下载 `ChuShi-NewTab-v1.3.0.zip`，Edge 扩展管理页「重新加载」或移除后重装。
- 旧「液态玻璃」预设无需重新导入：新预设包首次导入后自动按新引擎渲染；建议删除旧版重新导入本包内 `液态玻璃预设.json` 以获得「覆盖范围」设置项。
