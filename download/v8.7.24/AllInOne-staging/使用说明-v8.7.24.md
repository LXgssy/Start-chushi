# 初始 · Start v8.7.24 交付说明（beta）

## 本包内容
- ChuShi-NewTab-v8.7.24.zip —— 扩展本体（本版：播放器六项迭代）
- ChuShi-CloudSnapshot-v8.7.24.zip —— 云端快照载荷
- 初始SMTC音乐预设.cshz —— SMTC 桥接音乐面板预设（存量）
- 初始网易云播放器预设.cshz —— 方案二网易云直链播放器预设（本版六项迭代同步内置）
- 焕新示例预设.json —— 页面焕新预设（存量）
- ChuShi-Music-Bridge-8.4.0.zip —— SMTC 桥（沿用 8.4.0，无需更新）
- ChuShi-Lyric-Source-7.3.0.plugin —— 歌词源插件（沿用）

## 安装（升级）
1. 解压 ChuShi-NewTab-v8.7.24.zip → chrome://extensions → 开发者模式 → 「加载已解压」指向解压目录
   （老用户：删旧目录重解压 = 全新安装，无增量权限审批）
2. 已装网易云播放器预设的用户：⌘K → 官方预设 → 重新安装「网易云播放器预设」即得新版（或删旧 preset 重装）

## 本版六项迭代（网易云播放器）
- 点击封面打开歌词页（原「词」钮职责移交封面）
- 歌词页动效对标 SMTC 面板：呼吸缩放 + 高斯景深 + 已唱渐隐 + 翻译行平滑展开；背景加实（浅 .88 / 深 .86）可读性根修
- 播放器歌词接入全局歌词浮层与悬浮浮窗：内置播放器一开声，所有网页立即跟随；网页浮窗可直接控制（播放/暂停/切歌/拖进度）
- 音量改滑块无极调节（拖拽即改、自动记忆；喇叭图标=一键静音）
- 「词」钮改为全局歌词浮层开关（与音乐面板词钮同通道）
- 播放页新增退出登录：点账号徽标两步确认即退
