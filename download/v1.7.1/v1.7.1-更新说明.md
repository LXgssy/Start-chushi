# 「初始」v1.7.1 更新说明

> 发布日期：2026-09-04 · 上个版本：v1.7.0（液态玻璃撤下 + 通用换材质 + 八维焕新）

本版为**体验修缮批**，集中处理 v1.7.0 上线后的一批实测反馈，无破坏性变更。

## 一、图形化预设开发工具（preset-studio）

- **新增 `.cshz` 预设包导出**：「下载 .cshz 包」成为主按钮——工具内内置零依赖 zip 写入器（STORE + CRC32），把预设主体打包为官方 `.cshz` 包（manifest.json 结构，与「初始」导入端 pack.ts 约定一致），下载后直接拖进导入面板即装；`.json` 下载与复制保留为辅助途径。
- **显示修复**：表单里「＋ 添加命令 / 磁贴 / 栏按钮」等虚线按钮此前溢出面板被裁切（`all: unset` 重置 `box-sizing` 所致，已修复并为按钮补回 box-sizing 与焦点环）；动态项卡片右侧留出让位悬浮 × 删除钮；「使用说明」弹窗超高时不可滚动（补 `max-height + overflow`）。
- **功能性修复**：名称/作者/主题令牌/动效语言/时钟格式/布局等**静态字段此前不触发 JSON 实时刷新**（只有编辑动态列表才会重算），现全部字段即改即算，右侧 JSON 与完整性提示始终同步。
- 校验补强：tab 栏按钮的「打开网址」动作补 `https://` 前缀提示；时钟格式区新增语义说明（见下）。

## 二、tab 栏选框动效（三段式）

- **出现**（打开面板时首次出现）：Q 弹出场保留不变（scale 0.6 → 1 过冲回弹）。
- **切换**（面板之间切换）：恢复基线标准弹簧手感（420/34，与 v1.1.x 一致）——切换不再重播 Q 弹；**Q 弹滑移交由动效语言 playful 档**承担，官方「焕新示例预设」即用 playful 档，等于这个动画被收进示例预设。
- **消失**（关闭面板）：补上缺失的退场动画——快速缩回 + 淡出（0.16s 退场加速曲线，与出场对称）。

## 三、导入预设面板

- 拖入文件时出现的「松开即导入该预设文件」提示词与**错误列表**改为高度形变动画（0 → auto 展开 / 折回），下方的导入按钮等控件被平滑推下/收回，不再瞬跳。

## 四、右键菜单

- PC 端新增「**批量管理磁贴**」：直达磁贴编辑模式（与触屏长按同一模式）——点 × 逐个删除、点磁贴逐个编辑、拖拽排序，点击空白处退出；进入时给出操作提示 toast。

## 五、预设时钟语义修正（逻辑修复）

- 原逻辑：预设 `clock.hour12 / showSeconds` 声明式覆写用户设置——**预设装着时，设置面板怎么调都无效**（面板值永远被遮蔽）。
- 新逻辑：`hour12 / showSeconds` 在**安装时一次性合入用户设置**（与 `settings` 字段同律），之后随时可在设置面板调整，删除预设不回滚；`showDate`（日期行显隐）与 `greeting`（问候模板）无面板控件，保持声明式覆写、删除预设即还原。文档（开发者文档 §07b、README、开发工具内说明）已同步。

## 升级方式

- 网页版：直接访问 https://lxgssy.github.io/Start-chushi/ （PWA/Service Worker 会在后台更新缓存，重开标签页即新版）。
- 扩展版：`ChuShi-NewTab-v1.7.1.zip` 解压后在 Edge/Chrome 扩展管理页「重新加载」。

端到端 25/25 通过（studio 布局与 .cshz 回环导入、时钟一次性合入 + 面板调回、选框三段动效、拖拽提示形变、批量管理、pageerror=0）；扩展冒烟 7/7 通过。
