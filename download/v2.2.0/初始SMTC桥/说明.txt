「初始」SMTC 桥 v1.6.0
====================
手动：双击「启动SMTC桥.bat」（可见窗口，诊断用，关窗即停）。
常驻：双击「添加开机自启.bat」——之后每次开机经 bridge-hidden.vbs 静默拉起，
  全程零窗口；已注册自启的老用户启动一次新桥即自动改指当前目录（自愈升级），
  手动启动新桥时会自动接管旧实例占用的端口。
v1.6.0：seek 命令带 id 下发插件（内部 dispatch API → el.currentTime 兑底，
  双级实测校验，seekAck 回传）+ 插件版本透传（面板页脚可诊断）+ 自愈自启
  + 旧实例接管 + 静默 vbs 自启（不再多开窗口）。
v1.5.0：插件真值锚定 + seek 插件直通 + 歌词 rev 校验 + 暂停半窗补偿。
v1.3.0/v1.4.0：SMTC 位置时钟补偿 / 暂停恢复连续位置锚点。
