# 初始 ChuShi v1.1.2 更新说明

> 本批对应你反馈的五项问题，全部已修复并上线：
> 网页版 https://lxgssy.github.io/Start-chushi/ · 扩展 Release v1.1.2

## 1. 液态玻璃折射——已写进玻璃里面

**你看到的病根**：折射滤镜原本排在模糊前面（`url() blur()`），边缘的透镜弯曲被 6px 霜化糊成了雾，所以玻璃里看不到折射。

**修法（v1.1.2 链序律）**：
- 滤镜链改为 **`blur(3px) url(#位移贴图) saturate(180%)`**——先霜化背景、再重采样折射，弯曲保持锐利；
- 折射强度 0.6 → **0.75**，缺省模糊 6 → **3px**，饱和 170 → 180%；
- 官方「液态玻璃预设.json」参数同步更新，导入即用。

## 2. 开发者文档遮挡——已根治

文档原来嵌在 ⌘K 卡片 DOM 里，⌘K 卡是带 `will-change:transform + overflow-hidden` 的形变盒，全屏 fixed 层被它当成包含块并裁剪 → 大面积被挡。现改为 **React Portal 直挂 body**，彻底逃出形变舞台的堆叠/裁剪上下文（含 SSR 水合零差异处理）。

## 3. 「返回上一级」按钮——已加

文档顶栏左侧新增 **← 返回上一级**，一键回到 ⌘K 的预设视图；右侧 X 关闭不变，Esc 只关文档不穿透全局链。

## 4. 开发者文档已同步 GitHub

完整文档（268 行：预设包结构、字段白名单、`effects.glass` 参数表、沙箱脚本、打包与导入流程）已入仓：`docs/PRESET_DEV.md`（随 v1.1.2 提交 d2d8c0b 推送）。

## 5. 右键菜单——鼠标原点弹出动画 + 文档入口

- **弹出动画**：菜单以鼠标点击坐标为 `transform-origin`「从鼠标点长出来」（Q 弹 spring 曲线 0.2s）；屏幕边缘自动翻转方向时，原点同步翻转（向下展开 top / 向上 bottom / 向右 left / 向左 right），右键换位同律；
- **开发者文档入口**：右键菜单新增「📖 开发者文档」项，随时直达全屏文档；
- 关闭动画 0.12s 收拢回原点，对称成套。
