# 初始 · Start v8.7.25 交付说明（beta）

## 本包内容
- ChuShi-NewTab-v8.7.25.zip —— 扩展本体（本版：播放器传输键恒定居中）
- ChuShi-CloudSnapshot-v8.7.25.zip —— 云端快照载荷

## 安装（升级）
1. 解压 ChuShi-NewTab-v8.7.25.zip → chrome://extensions → 开发者模式 → 「加载已解压」指向解压目录
   （老用户：删旧目录重解压 = 全新安装，无增量权限审批）
2. 已装网易云播放器预设的用户：⌘K → 官方预设 → 重新安装「网易云播放器预设」即得新版（或删旧 preset 重装）
