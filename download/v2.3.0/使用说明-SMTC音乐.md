# 「初始」SMTC 音乐 · v2.3.0 使用说明

> 本轮按你的思路彻底重构：**抛弃独立 SMTC 桥文件，全部集成进网易云插件**。
> Windows 侧从此只需要装 **一个 .plugin 文件**，其余全自动。

---

## 一、v2.3.0 做了什么

### 1. 一体化插件（初始歌词源 v1.3.0 = 唯一的 Windows 侧文件）
插件内部**内嵌了完整的 SMTC 桥**（PowerShell 脚本，纯 ASCII 编码，绝无乱码可能），
装好插件后它会自动完成一切，你不再需要任何 bat / 窗口 / 手动步骤：
- **自动部署**：把内嵌桥写到 BetterNCM 数据目录 `chushi-bridge/`
- **自动拉起**：经 BetterNCM 的 `app.exec` 静默启动（**零窗口**）
- **自动升级**：每 20 秒健康检查，发现桥缺失或版本旧 → 重新部署并拉起新版
  （新版桥自带版本仲裁：旧实例被自动接管，同版本则静默让路）
- **自动开机自启**：桥启动时自己写好 Run 键，重启电脑也零窗口运行
- **生命周期**：桥随插件版本走，**版本漂移结构性消灭**

### 2. seek 走网易云自家原生 RPC（你说的 channel.seek 思路，找到了实证）
通过劫持分析确认：网易云自家进度条拖动走的就是
`channel.call("audioplayer.seek", cb, [songId, "songId|seek|随机串", 秒])`。
插件 v1.3.0 的 seek 三级阶梯：
1. **channel.call("audioplayer.seek")** —— 客户端正门，与本体 UI 同源
2. **store.dispatch("playing/setPlayingPosition")** —— 内部 API（420ms 校验后启用）
3. **el.currentTime 直写** —— 元素级末级兜底
每级 420ms 后用播放元素实测校验；三级全败则把 seekAck=false 回传宿主——
**面板会立刻弹回真实位置并弹出醒目提示芯片**，绝不再「假装跳转」。

### 3. 拖动失败提示终于看得见了
v2.2.0 的提示藏在 10.5px 页脚文字里（你完全看不到，这个反馈是对的）。
v2.3.0 改为**进度条正上方的醒目芯片**，出现 3.8 秒自动消失。

### 4. 组件过旧芯片（版本漂移从「看不见」变「症状可见」）
桥版本 <1.7.0 或插件 <1.3.0 或插件不在场 → 面板顶部常驻橙色芯片
「组件过旧 · 更新初始歌词源 .plugin 后重启网易云即可全自动修复」。

### 5. 300ms 快命令通道
新增 `/api/plugin/cmd` 轮询接口，seek 命令延迟从 ≤1s 降到 ≤300ms。

### 6. 暂停→恢复漂移的进一步加固
除 v2.2.0 的「插件真值绝对锚定」外，v1.3.0 插件修复了一个真实漂移源：
换源/缓冲过场中媒体元素选择可能命中预加载空元素（进度瞬间报 0 → 恢复后错位），
现在采用**粘滞元素选择**（5 秒内沿用上一个活跃元素）。
> 说明：v2.3.0 之前你看到的持续漂移/错位，大概率是桥或插件停在旧版
> （旧版没有真值锚定链路）——一体化架构让这成为不可能，芯片也会直接告诉你。

## 二、升级步骤（只剩两步）

1. **网页版** Ctrl+F5 强刷；**扩展版**重装 v2.3.0 zip
2. **网易云**：把 `初始歌词源-1.3.0.plugin` 放进 BetterNCM 的 plugins 文件夹
   （**删掉旧版 1.2.0/1.1.0/1.0.0**）→ 重启网易云 → 放首歌
   （旧的手动桥窗口可以全部关掉，不再需要；旧的「启动SMTC桥.bat」文件夹可整包删除）
3. ⌘K → 预设 → 删除旧「初始 · SMTC 音乐」→ 导入新 `初始SMTC音乐预设.cshz`

## 三、自检清单（2 分钟）

1. 放歌 → 面板亮起、歌词滚动、页脚显示 `已连接 · 网易云音乐 · 插件 v1.3.0`
2. 面板顶部**没有**橙色「组件过旧」芯片（有 = 组件没换干净）
3. 拖动进度条 → 网易云本体跟着跳（audioplayer.seek 正门生效）
4. 拖到头再拖回来、暂停 5 秒再继续 → 无跳变、歌词不漂
5. 若拖动后出现「拖动未生效」芯片 → 把网易云客户端版本号发我（诚实回退，
   说明三级阶梯在你的客户端版本上全部未生效，需要我再找通道）

## 四、常见问题

- **桥在哪？还用什么启动？** 不用管。它被插件内嵌并自动部署在
  BetterNCM 数据目录的 `chushi-bridge/` 里，开机自启、静默运行、自动升级。
- **想看桥的状态？** 打开网易云按 F12 → Console 过滤 `[ChuShiLyricSource]`，
  有部署/拉起/健康检查/seek 生效的完整日志。
- **防误解**：Windows 不允许浏览器页面直接读系统媒体状态，所以那个看不见的
  本机小进程在物理上必须存在——但它现在是插件「身体的一部分」：
  插件部署它、升级它、监督它，你只面对一个 .plugin 文件。
