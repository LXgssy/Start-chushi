# 「初始」v8.2.4 使用说明（电流音根治 + 律动复活 + 稳定性重构）

## 本版修什么（实机反馈三连全落地）

### ① 扬声器电流音——根治（两刀）

- **刀一 · 按需采集**：频谱助手以前「只要在跑就一直抓系统声音」；
  现在没人看频谱（面板没开、浮窗没在放歌页面）超过 10 秒，就把采集
  管道从音频引擎上摘下来（零音频栈参与），有人看再 200ms 内接回去。
  你观察到的「关闭网页后电流音消失」反过来证明：噪声窗 = 采集窗
- **刀二 · 优雅退出**：以前助手每 60 秒空闲自爆、hub 再拉起，每 ~80 秒
  一轮「强杀活跃音频客户端再新建」的循环（日志实锤整整一下午都在
  循环）；现在退出前把 loopback 客户端 Stop/Release/COM 卸载全部
  干净走完，浏览态零消费者时**根本不再拉起**（按需门）
- 附加加固：采集线程挂 MMCSS "Pro Audio" 调度档、设备失效风暴退避
  800ms→5s、初始化于静默期「永不产包」的驱动 bug 有 15s 零包保险

### ② 律动还是不动——真凶抓到了（不是玄学）

- 你的 spectrum-log 里 `bass=1.000` **每一行都恒钉 1.0**：FFT 频段能量
  忘了折算 FFT 增益（Hann 窗把幅度放大 ~512 倍），常规音乐所有频段
  全部饱和到 1.0 → 高光恒亮不跳 = 「没有律动」
- 现在按 bin 幅度折回幅域再归一（-60dB..0dB 窗）：满幅 ≈0.95、常规
  音乐 0.3~0.8 **随鼓点起伏**（本版带数学回归门：静音 0 / 0.25 正弦
  0.43 / 满幅 0.73，旧公式对照组 v=1.64 必钉死）
- 装上本版后如果还不跳，看日志 `[dsp]` 行：bass 应在 0~1 之间**摆动**；
  cap=0 说明输出设备不是系统默认设备（loopback 只能听默认设备）

### ③ 稳定性：面板经常重连 + 浮窗控制不灵——根治

- hub 是「串行单连接」服务器，旧版把频谱助手的探测/拉起内联在状态
  心跳热路里，拉起被杀软扫描卡住时（可达秒级）所有请求排队 → 面板
  超时误判掉线重连、浮窗命令 POST 超时 = 控制失灵
- 现在：探测/拉起全部搬进独立 keeper 线程（5s 节拍），请求热路零阻塞；
  拉起加「需求门」（120s 内有真频谱消费者才许拉起）；浮窗侧频谱轮询
  加在飞守卫 + 发现退避 5s

### ④ 真 yrc 逐字歌词「播放完动画就结束高亮」——根治

- 真因：逐字行唱完后 200ms 进入「行间间隙」，渲染层把整行扫光重算
  回 0 = 高光塌掉；「强行逐字」的估算行不会进这个分支所以没这病
- 现在：行尾间隙期扫光**挂住 100%**，下一行开始才随已唱灰渐隐
  （浮窗 + 面板同律补门）

## 升级步骤（本版两件必换）

1. 「初始」页更新到 v8.2.4（覆盖安装 `ChuShi-NewTab-v8.2.4.zip`：**删净旧解压目录** → 解压新包 → 扩展页点刷新）
2. 更新桥插件到 **8.2.4**（**必换**：助手/hub 三连修——替换插件目录后**重启网易云**）
3. SMTC 音乐预设 **8.2.4**（**必换**：面板保持门——⌘K 导入新 cshz）；
   歌词源 7.3.0 沿用无需动

## 排障口令（如果还有问题）

- 电流音是否还有？→ 关掉所有「初始」页面 + 隐藏浮窗（右键），10 秒后
  应该看到日志 `[cap] no consumer 10s — loopback paused`（采集已停）
- 律动是否复活？→ 日志 `[dsp]` 行 bass 不再恒 1.000；pkts 在涨
- 面板是否还重连？→ hub 日志不应再出现请求热路拉起；`[spec] demand
  fresh & helper absent — spawning (keeper)` 只在你真的打开面板/浮窗时出现
