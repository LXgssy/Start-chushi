# 「初始」v8.2.8 使用说明（强行逐字跟随 + 歌词时序三修 + 形变动画 + 降延迟）

## 本版修了什么（全部来自你的实机反馈）

### ① 浮窗支持「强行逐字」跟随
「初始」面板里开的强行逐字开关，现在会**自动同步给浮窗**：开关开着 → 浮
窗完全体里的 lrc 歌词也走逐字扫光（估算时间轴）；关 → 逐行高亮。切换开
关浮窗立即跟随，无需刷新。（真逐字 yrc 歌曲不受开关影响，恒逐字。）

### ② 跳转后歌词对不上——根治（逐行尤严重的真凶）
考古实锤：跳转落进**间奏**时，歌词区只对账了高亮状态，**滚动位置没跟
过去**——停在跳转前的旧位置，直到下一句开唱才猛跳过去。长间奏（十几秒）
里整块歌词区完全错位，逐行歌词行距长、间奏多，所以最明显。本版：跳转跨
间奏落入时歌词区**立即平滑滚到已唱界行**。同时桥命令后 500/1200ms 补拉
两次真值（网易云执行跳转需要几百毫秒），歌词/进度更快对上。

### ③ 伴奏期逐字高亮缓慢爬行——根治
部分歌曲的末词时长被拖进长伴奏（时间轴数据如此）。本版加了**末词行尾硬
终点**：末词时长对行内其他词的均长离群（>2.2 倍）时，扫光在均长 1.8 倍
内收完并定格——唱完即停，伴奏段不再缓慢爬行。正常歌（含真拖腔）不受影响。

### ④ 「逐字比唱的更快」——歌词延迟补偿
SMTC 播放位置天然**领先**实际听到的声音约 60-100ms（Windows 音频引擎+
设备缓冲；之前高光链路不稳所以没显形）。本版歌词对齐统一延后 100ms——
扫光等唱声到位。进度条/时间显示不受影响。

### ⑤ 去方框 + 全频段细腻律动
v8.2.7 的细节环（方框）废弃——三轴全部融入**封面本体与光晕本体**：低音
管提亮+光晕主推+对比微脉冲，中频管亮度+光晕次推+光晕尺寸，高频管饱和+
光晕点缀；小信号经非线性曲线提可见度，中高频攻快放快（跟手细腻）、低音
慢放（鼓点余韵）。光没有边界，只有呼吸。

### ⑥ 三态切换「形变」动画（dock 同语言）
标准态↔封面态：**长方形面板变形成封面大小的正方形**再无缝接管（收缩）/
从正方形长成长方形（展开）；标准态↔完全体：长方形互变。封面图全程连续
飞形（唯一连续锚），内容在形变大半后淡入——不挤压不穿帮，与「初始」dock
面板弹出同一动画语言。系统开启「减少动态」自动直切。

### ⑦ 律动延迟降低
频谱 FFT 节流 50→25ms（40Hz）、扩展轮询 50→33ms（30Hz）、包络更快到峰
——端到端延迟均值约 130ms→90ms，鼓点跟手度明显提升。

## 升级步骤（三件必换）

1. 「初始」页更新到 v8.2.8（覆盖安装 `ChuShi-NewTab-v8.2.8.zip`：**删净旧
   解压目录** → 解压新包 → 扩展页点刷新）
2. 桥更新到 **8.2.8** 并**重启网易云**（频谱 40Hz 在桥侧 native 二进制里）
3. **⌘K 重新导入** SMTC 音乐预设 **8.2.8**（面板去框化+间奏滚动）
4. 歌词源 7.3.0 沿用无需动

## 装完怎么自查

- 面板开强行逐字 → 浮窗完全体 lrc 歌词也逐字扫光
- 播放中跳转到长间奏 → 歌词区立即滚到正确位置，不再停留旧位
- 末词唱完进伴奏 → 扫光定格不再缓慢爬行
- 逐字与唱声的先后关系应明显改善（不再明显超前）
- 光效无方框：封面亮度/光晕呼吸覆盖高中低音，光没有边界
- 三态互切：长方形⇄正方形形变 + 封面连续飞形，无跳切
- 鼓点跟手度应比上一版更紧（延迟降低 ~40ms）
- 歌词/拖动/零跳转等 31 项 e2e 回归全绿
