# 初始 · Start v8.7.23 交付说明（beta）

## 本包内容
- ChuShi-NewTab-v8.7.23.zip —— 扩展本体（本版新增：内置网易云播放器预设）
- ChuShi-CloudSnapshot-v8.7.23.zip —— 云端快照载荷
- 初始SMTC音乐预设.cshz —— SMTC 桥接音乐面板预设（存量）
- **初始网易云播放器预设.cshz —— 新增：方案二网易云直链播放器预设**
- 焕新示例预设.json —— 页面焕新预设（存量）
- ChuShi-Music-Bridge-8.4.0.zip —— SMTC 桥（沿用 8.4.0，无需更新）
- ChuShi-Lyric-Source-7.3.0.plugin —— 歌词源插件（沿用）

## 安装（升级）
1. 解压 ChuShi-NewTab-v8.7.23.zip → chrome://extensions → 开发者模式 → 「加载已解压」指向解压目录
   （老用户：删旧目录重解压 = 全新安装，无增量权限审批）
2. ⌘K → 官方预设 → 安装「网易云播放器预设」→ dock 出现黑胶唱片按钮 → 点击弹出播放面板

## 网易云播放器（方案二）要点
- 免登录即可用：搜索 / 每日推荐 / 播放免费歌
- 「我的歌单」页签扫码登录（手机网易云 App 扫一扫）；浏览器登录过网易云网页版则自动继承登录态
- VIP / 灰色歌曲跟账号权限走：无权限提示「暂无法播放」，VIP 账号登录后可播
- 播放走系统媒体会话（MediaSession）：Windows 媒体浮层 / 现有 SMTC 音乐面板 / 全局歌词可联动
- 数据层端点白名单由扩展宿主复核代理，widget 沙箱零跨域面；凭证仅存浏览器 cookie jar，不落盘不同步
