# 「初始」v1.7.0 更新说明

## 本次核心：液态玻璃正式撤下，通用「换材质」登场

经过多轮尝试与评估，**液态玻璃无法真正移植到「初始」**——它带来的复杂度、性能开销与体验缺陷（tab 栏拖累、面板不适配、拖拽不跟随等）与「初始」克制的极简气质相悖。本次正式做出架构决定：

- **宿主代码零液态玻璃**：所有液态玻璃相关代码从「初始」中删除，官方「液态玻璃」预设一并撤下；
- **通用换材质接口**：新增 `chushi.material.apply / reset` API——宿主不内建任何具体材质，只提供一块受控的「材质作用面」。亚克力、Mica、液态玻璃、Win UI 等任何风格，都可以由预设脚本经这个接口自行实现；
- 这意味着：想要什么质感，社区都能自己做；「初始」本体保持轻、快、克制。

## 八个焕新作用面（本次新增四个）

| 维度 | 字段 / API | 说明 |
|---|---|---|
| 材质 | `chushi.material`（新） | 整页玻璃换装：css 直接写公开元素钩子，重复调用幂等替换，删除预设即还原 |
| 内容 | `commands / links / dock / pages / widgets / scripts` | 命令、磁贴、栏按钮、沙箱页面、角落小部件、数据源脚本 |
| 排版 | `layout` | 区块显隐、时钟缩放、磁贴列数、垂直对齐 |
| 图标（新） | `icons` | 把 tab 栏六个内建按钮换成内置图标名或 base64 图片 |
| 主题令牌（新） | `tokens` | 覆写强调色与 tab 栏选框/分隔线四个主题令牌 |
| 动效语言（新） | `motion` | 弹簧档位 standard / playful / calm / instant + 入场动画倍率 0.5–2 |
| 时钟格式（新） | `clock` | 12/24 小时制、秒数、日期行、问候语模板（`{greet}`/`{name}` 占位） |
| 动画 | `animations` | 自定义 CSS（净化后注入，公开元素钩子） |

官方 **「焕新示例预设」**（`examples/焕新示例预设.json`）一次覆盖全部八个维度：Fluent 亚克力材质 + 磁贴内容 + 排版 + 微动效 + 图标替换 + Fluent 蓝令牌 + Q 弹动效 + 12 小时时钟与问候模板——导入即见效，删除即还原。

## 图形化预设开发工具（内嵌离线版）

⌘K → 导入预设 → **「开发工具」**按钮：一键下载官方图形化开发工具。它是内嵌在「初始」里的**单文件离线 HTML 应用**——不依赖任何服务器，断网也能下载；下载后双击在任意浏览器打开即可：

- 表单式编辑全部声明式字段（命令 / 磁贴 / 图标 / 令牌 / 动效 / 时钟 / 布局 / 样式 / 脚本）；
- 实时生成 JSON + 完整性提示；
- 内嵌使用说明（三步上手、作用面速查、换材质示例、上限速查）。

## 界面修正

- **tab 栏选框 Q 弹出场**：点击 tab 时选框从 0.6 缩放过冲回弹到 1（backOut 型弹簧，非液态玻璃样式）；按钮间滑动保持原有弹簧手感；
- 随液态玻璃撤下，tab 栏上不再有任何液态玻璃折射动画；
- 右键菜单与开发者文档的级联模糊过场保持不变。

## 升级方式

- **网页版**：直接访问 <https://lxgssy.github.io/Start-chushi/>（Service Worker 自动换装新版本）；
- **扩展版**：从 [Releases](https://github.com/LXgssy/Start-chushi/releases) 下载 `ChuShi-NewTab-v1.7.0.zip` 解压，在 `edge://extensions` 中「重新加载」或按 README 开发者模式重新加载。

> 若此前安装过官方「液态玻璃」预设：升级后它会因引擎接口变化而不再生效，在 ⌘K → 管理预设中删除即可（页面上不会有残留）。
