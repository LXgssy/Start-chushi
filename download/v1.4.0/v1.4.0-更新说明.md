# 初始 · ChuShi v1.4.0 更新说明

**液态玻璃引擎收编内建「初始」：实时渲染 + Apple 同向折射 + 覆盖范围扩容，预设包一句调用**

> 本版回应：「液态玻璃光靠预设包效果还是不行，直接写进『初始』里面吧，然后通过预设包调用出来；玻璃不会实时渲染、覆盖范围不够。」

## 一、架构定稿：引擎写进「初始」，预设包只调用

v1.1.3–v1.3.0 三版把引擎放在预设包脚本里跑（含 v1.3.0 的 WebGL 画布方案），始终受沙箱环境根本限制：沙箱 iframe 是 `display:none` 隐藏文档，Chromium 对隐藏文档**暂停渲染循环（rAF 永不触发）**；每次几何变化都要消息桥往返搬运/重建。这就是「玻璃不会实时渲染」的根源——任何预设包方案都绕不过去。

v1.4.0 把引擎**收编内建于宿主**（`liquid-glass.ts`，约 600 行 TypeScript）：引擎在可见文档中以 rAF 逐帧追踪玻璃几何。预设包只经新 API **`chushi.glass.enable / patch / disable`** 一句调用，官方「液态玻璃」预设瘦身到 1.8KB（注册设置面板八项调节 + 调用引擎）。

## 二、实时渲染：动画期间折射全程在线

- **逐帧几何追踪**：rAF 循环每帧读取玻璃元素实测盒，transform 弹簧、高度弹簧、CSS transition 全覆盖；
- **变动期贴图实时重建**：几何变化期间以 1/4 分辨率按 ~30fps 连续重建位移贴图（折射不缺席）；几何稳定约 160ms 后自动换半分辨率精贴图；
- **无空窗帧**：新贴图经 Image 预解码、就绪后原子替换 feImage href，旧贴图保持显示——旧版「退化纯模糊再弹回」的闪动路径彻底移除；
- 实测（Playwright 探针）：面板高度弹簧 ~900ms 内贴图重建 5 版、0 掉链帧；引擎**零几何侵入**（不改元素 border/margin/width，布局无扰）。

## 三、物理：负量内采样（Apple / Kyant0 同向）

v1.3.0 已实证：Apple 液态玻璃边缘折射 = **位移沿外法线取负**——边缘采样点向玻璃内偏，凸透镜放大（与 Kyant0/AndroidLiquidGlass 默认 refractionAmount −24dp 同向）。v1.4.0 引擎内置该律，且比 WebGL 方案更轻：经 SVG `feDisplacementMap` **负 scale** 直接实现，无需 canvas 自绘与位图搬运；剖面 smoothstep² 集中边缘窄带，SDF 梯度方向保证长边弯曲垂直于边缘；可选三通道色散；链序律 blur → url(#disp) → saturate 内置。

## 四、覆盖范围扩容

- 注册表扩到**全部玻璃面**：搜索栏 / 底部栏 / 面板卡片 / 全站玻璃卡（⌘K、对话框、右键菜单、开发者文档）+ **天气玻璃芯片**（full 模式新增）；
- 新增设置项**「覆盖范围」**（分段选择）：`全部玻璃面`（默认）/ `基础四区`，收窄即时生效；
- 全屏幕布（⌘K / 对话框遮罩）依旧永不折射——幕布不是玻璃块。

## 五、同批保留与文档

- v1.3.0 的两个「整页焕新」作用面**原样保留**：图标替换（`chushi.icons.override`，Dock/搜索槽位换图）与主题令牌覆写（`chushi.theme.override`，亮/暗双域 28 项白名单）；
