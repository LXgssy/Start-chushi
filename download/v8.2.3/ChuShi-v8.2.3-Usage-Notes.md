# 「初始」v8.2.3 使用说明（高光归位 + 主题色联动 + 律动复活）

## 本版修什么（实机反馈四连全落地）

### ① 浮窗「高光跑封面上」——根治

- 真因：封面辉光（.glow）是绝对定位且没有层级，画在了封面图**上面**，
  再被封面容器裁剪，紫色糊了整张封面
- 修法：封面图压住辉光（层级律 + 去裁剪）——辉光和「初始」面板一样
  从封面**四周晕出去**，封面本身永远清晰

### ② 逐字歌词两色调——行切换不再「白高光看着在上一行」

- 当前行的**未唱词**底色提亮一档（未来灰 < 已唱灰 < 当前未唱 < 扫光白
  四级阶梯），行切换的交叉渐隐窗口里当前行恒为视觉主角
- 浮窗与「初始」面板同律双改

### ③ 标准态顶带「太空」——填充

- 顶带 30→26px 收敛，**带左常显当前播放时间**（mini 态实时走针，
  修了时间只在完全体走针会冻在 0:00 的问题）——空带不再空
- 态切换时时间强制重写（防残留旧值）

### ④ 助手在跑但浮窗/面板律动全死——三连修

- **冻环复读根治**：音频设备没有活跃流时 loopback 不产包，旧版对冻结
  环每 48ms 重跑 FFT = 停机瞬间的频谱被永久复读（辉光恒亮不跳的真身）；
  现在超过 600ms 无非静音包直接发布零快照
- **默认设备变更跟踪**：换输出设备/应用换输出后 2s 内自动重连新设备
- **可诊断性**：助手日志（%LOCALAPPDATA%\ChuShi\spectrum-log.txt）新增
  每 10s 健康心跳 `[dsp] pkts/lvl/bass/cap/served/port` + 首个频谱客户端
  留痕——下一轮如果律动还是不对，日志一眼能看出是采集面还是消费面
- 请顺手确认：**网易云的输出设备 = 系统默认输出设备**（loopback 只能
  听默认设备；耳机/扬声器切换后本版会自动跟随默认设备）

### ⑤ 浮窗主题色跟随「初始」强调色

- 「初始」设置里改强调色 → 浮窗（所有网页上的悬浮卡）实时跟随
  （播放键/进度条/辉光/封面占位全部换色），无需重启

## 升级步骤（本版两件必换）

1. 「初始」页更新到 v8.2.3（覆盖安装 `ChuShi-NewTab-v8.2.3.zip`：**删净旧解压目录** → 解压新包 → 扩展页点刷新）
2. 更新桥插件到 **8.2.3**（**必换**：助手 8.2.3 冻环根治——替换插件目录后**重启网易云**）
3. SMTC 音乐预设 **8.2.3**（**必换**：面板两色调——⌘K 导入新 cshz）；
   歌词源 7.3.0 沿用无需动
