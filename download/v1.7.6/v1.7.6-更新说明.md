# 初始 v1.7.6 更新说明 — 初始音乐桥·独立版（摆脱 BetterNCM 框架）

## 这一批发生了什么

**背景**：v1.7.5 的音乐面板依赖 chromatic（BetterNCMII）插件框架把桥接插件装进网易云音乐。
但 BetterNCM 项目已实际停更于网易云（作者迁移至 QQ 音乐开发，仓库整体改名/重写为
chromatic，而 chromatic 2.0 是通用注入工具链、**没有发布任何可用二进制**）——
用户能装的最后一版 BetterNCMII 1.3.4 停在 2024 年 10 月，**无法适配最新的网易云客户端**，
这也是「桥接插件装了没反应」的根本原因：框架本身没有注入成功，插件自然无从加载。

**本版方案**：「初始音乐桥」升级为**独立版 ChuShiBridge**，不再依赖 BetterNCM/chromatic：

1. **ChuShiBridge.exe（桥接主体）**
   - 以 `--remote-debugging-port` 代启网易云音乐，走 **CEF 调试协议（CDP）** 附加主页面；
   - 不 hook 网易云任何内部函数（BetterNCM 的 CEF hook 正是随版本升级失效的根源），
     **不随网易云升级而失效**；
   - 页内桥三路采集「正在播放」：dva Redux store（元数据）+ 原生播放事件
     PlayState/PlayProgress/Seek（播放态）+ 页面媒体元素（音频真源），多策略降级；
   - 在 `127.0.0.1:10754`（占用自动顺延）提供与 v1.7.5 插件版**完全同契约**的 HTTP API
     ——「初始」侧客户端零改动；
   - 新增 `/api/debug` 排障端点 + `%LOCALAPPDATA%\ChuShiBridge\bridge.log` 日志。
2. **msimg32.dll（装载器，可选）**
   - BetterNCM 同款 msimg32 代理劫持位（放网易云目录），但只做一件事：
     在进程初始化早期把 CEF 调试端口开关**追加进 PEB 命令行**——
     用户双击网易云**原图标**也能开启桥接；幂等、仅主进程、零指令 patch；
3. **一键安装/卸载**
   - `安装初始音乐桥.bat`：自动定位网易云 → 架构检查（仅 x64 装装载器）→
     备份并替换已有 msimg32.dll（含 BetterNCM 场景）→ 装桥接器 →
     桌面快捷方式 → 可选开机自启 → 自动重启网易云 → 60s 健康检查；
   - `卸载初始音乐桥.bat`：停桥接器、还原装载器备份、删快捷方式与数据目录。

## 「初始」侧变化

- 音乐面板**接入指引改为三步**：下载一键安装包（面板内直链 Release 资产）→
  双击安装 → 回面板点「重试」；
- 保留旧版客户端（2.x/3.0.x）的 chromatic 插件路线链接（v1.7.5 Release）；
- 连接失败文案随新架构更新（「初始音乐桥未运行」）。

## 排障指引（连不上时）

1. 确认 ChuShiBridge 控制台窗口开着（显示「已附加网易云页面」即成功）；
2. 浏览器访问 `http://127.0.0.1:10754/api/debug`，重点看
   `ncmRunning`（网易云在跑吗）/ `cdp`（调试端口附加了吗）/ `bridge`（页内桥装上了吗）
   / `diag.store`（内部数据源可达吗）；
3. `%LOCALAPPDATA%\ChuShiBridge\bridge.log` 有全程日志；
4. 网页版首次连接浏览器可能询问「访问本地网络」权限，请允许（扩展版无需）。

## 安全设计（与 v1.7.5 同级，新增说明）

- 本机服务仅绑 127.0.0.1 + Origin 白名单（扩展族/「初始」线上域/localhost 族）；
- 控制命令仅 8 种固定动作白名单，请求体 ≤4KB；
- CDP 调试端口亦仅绑回环（Chromium 默认），仅本机可连——请勿手改 `--remote-allow-origins`
  以外的参数把端口暴露给局域网。

## 校验

- 页内桥 JS 在模拟网易云世界（webpack jsonp + dva store + legacyNativeCmder + 媒体元素）
  全路径对拍 37/37 通过；
- ChuShiBridge.exe / msimg32.dll llvm-mingw x86_64 编译零警告，导出表 5/5 自检通过；
- HTTP API 协议与 v1.7.5 mock 孪生对拍回归（verify-v176）通过；
- 双二进制无法在非 Windows 环境真机运行——真机首连请以 `/api/ping` 自证（说明文档已含）。
