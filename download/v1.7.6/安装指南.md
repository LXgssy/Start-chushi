# 初始音乐桥 · BetterNCM 插件路线 安装指南

本交付包含两件东西：

| 文件 | 说明 |
|------|------|
| `初始音乐桥-插件-1.1.0.zip` | 插件本体（BetterNCM/chromatic 插件，含 manifest.json / index.js / bridge.dll / 安装说明） |
| `betterncm_installer.exe` | BetterNCM 官方一键安装器（BetterNCM-Installer 1.2.0，来自 std-microblock/BetterNCM-Installer 官方 Release，SHA-256 f4aabe8f…） |

## 第一步：安装 BetterNCM 插件管理器

1. **完全退出**网易云音乐（含托盘）；
2. 双击 `betterncm_installer.exe`，按界面提示安装（会自动下载并注入
   BetterNCMII 运行时，需要联网）；
3. 重启网易云音乐，左侧出现「插件管理」即成功。

## 第二步：安装「初始音乐桥」插件

1. 解压 `初始音乐桥-插件-1.1.0.zip`，得到「初始音乐桥」文件夹；
2. 把整个文件夹放进 BetterNCM 数据目录的 `plugins_dev` 里（默认
   `C:\betterncm\plugins_dev\`），最终结构：
   ```
   C:\betterncm\plugins_dev\初始音乐桥\
     ├─ manifest.json
     ├─ index.js
     ├─ bridge.dll
     └─ 安装说明.txt
   ```
   （也可直接把 zip 拖进网易云「插件管理」界面安装）
3. 完全退出并重启网易云音乐；
4. 打开「初始」起始页 → 底部 Dock「音乐」面板 → 自动连接，
   显示歌曲后即可播放/暂停/切歌/拖进度/调音量。

## 自检与排障

- 浏览器打开 `http://127.0.0.1:10754/api/debug`：
  - 有输出 = bridge.dll 服务正常；`stateFile:false` = 插件 JS 没注入成功；
  - `diag` 段显示页内三源（storeReady / eventsHooked / media）与页面地址；
- 网易云内按 F12，Console 过滤 `[ChuShiMusicBridge]` 看注入日志；
- 详细 FAQ 见插件包内「安装说明.txt」。

## 已知边界（请先了解）

BetterNCM 框架最后一次适配发布（1.3.4）在 2024-10，未跟进网易云之后的新内核。
若安装管理器/插件后**网易云无法启动、或插件管理界面空白**，多为内核不兼容——
这不是插件的问题，而是框架的边界。此时请改用独立版路线（不依赖任何框架）：

- 「初始」Release 页 → `ChuShiBridge-2.0.0-Setup.zip`（当前内含桥接器 2.0.4）
- 解压后双击「安装初始音乐桥.bat」即可，网易云运行中也可直接装。

两条路线接口完全一致（同端口同 API），「初始」侧无需任何改动。
