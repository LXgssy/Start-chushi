# 「初始」SMTC 音乐面板 · v2.3.2 使用说明

## 本版修了什么（对应你录屏里的三个问题）

1. **「我插件是新的，面板却说旧」**
   真因：你机器的系统策略拦掉了新版桥的自动拉起（之前那次 WSH 弹窗 0x80070312 就是它），
   旧版桥进程一直占着端口不死，面板只能看到旧桥，于是永远提示「组件过旧」。
   v2.3.2 双管齐下：
   - 插件 v1.5.0 现在会**主动杀掉旧桥进程**再拉起新桥（cmd/netstat/taskkill 优先，powershell 兜底）；
   - 如果系统连杀进程都拦（自动升级彻底无望），面板芯片会**如实告诉你**去运行
     「手动启动桥（备用）」，**绝不再骗你「更新 .plugin 就能修」**——那个提示只在该提示的时候出现。

2. **播放状态反着来（网易云暂停面板显示播放，或反过来）**
   真因：旧逻辑在原生播放状态事件 5 秒「过期」后，去猜 DOM 里某个播放器元素的状态，
   猜到预加载/流浪元素就反了。v2.3.2 改为：状态事件是「最后一次说的就是现状」，永不过期；
   另用网易云内部 store 做交叉验证（矛盾超过 3 秒自动纠正）。

3. **进度条 0.5 倍速爬行 / 时间倒退**
   真因：每秒重新「评分选元素」偶尔选到流浪元素，读到一个陈旧的 currentTime。
   v2.3.2 给正确的元素上「身份锁」（同歌内不换人），并新增倒退熔断（无拖动时进度倒退
   超过 2.5 秒的样本直接丢弃）。

## 升级三步

1. **装新插件**：解压后双击 `初始歌词源-1.5.0.plugin`（或在网易云插件设置里安装），
   然后**完全退出并重启网易云音乐**（托盘右键退出才算完全退出）。
2. **更新网页/扩展**：浏览器打开新标签页按 `Ctrl+F5` 强刷（扩展则到扩展管理页点「重新加载」）。
3. **重新导入预设**：把 `初始SMTC音乐预设.cshz` 拖进新标签页导入（Command/Ctrl+K → 导入预设）。

页脚显示 `已连接 · NetEase Music · 插件 v1.5.0` 且顶部无橙色芯片 = 全部到位。

## 如果芯片提示「桥组件待升级（自动升级被系统拦截）」

说明你的机器策略连插件自动升级桥的路子也拦死了。手动兜底：

1. 打开交付包里的 `手动启动桥（备用）` 文件夹；
2. 双击 `启动SMTC桥.bat`（黑窗口一闪而过属正常，桥在后台运行）；
3. 回到新标签页 `Ctrl+F5`——芯片应当消失。
4. 想开机自启：`Win+R` 输入 `shell:startup`，把 `启动SMTC桥.bat` 的快捷方式放进去。

## 老问题备注

- **拖动进度条**：面板拖动 = 命令直达网易云原生接口（与网易云自家进度条同源）。
  若网易云没响应，进度条会诚实弹回并提示「拖动未生效」，不会假装跳转成功。
- **逐字歌词**：逐字（卡拉OK）与逐行歌词都支持；暂停后恢复，进度以网易云内部真值
  绝对重锚，不会累积漂移。
- 若面板完全无反应：确认网易云在播歌 → 看页脚是否「已连接」→ 未连接则走上面的手动兜底。
