# 「初始」SMTC 音乐 · 使用说明（v2.0.0）

> 本包 = **初始SMTC桥 v1.3.0**（PowerShell 零依赖）+ **初始歌词源 BetterNCM 插件 v1.0.0**（可选，逐字歌词）+ **初始SMTC音乐预设 .cshz**（dock 音乐按钮 + 弹出面板）。
> 音乐面板与「初始」内建面板共用同一套切换动画（模糊聚拢/散场 + 高度宽度弹簧）；歌词解析、进度插值、逐字对齐全部内建进「初始」（`chushi.music` API），面板只负责样式与渲染。

## 一、三步安装

1. **桥**（必须）：解压本目录 → 双击 `初始SMTC桥/启动SMTC桥.bat`
   - 窗口全英文提示属正常现象（纯 ASCII 终极防乱码方案）；保持窗口开着即桥在运行
   - 关闭窗口 = 停桥；建议双击 `添加开机自启.bat` 以后免手动
   - **从旧版本升级：把旧的 初始SMTC桥 目录整个删掉，换成本包的**（v1.3.0 修进度条冻结，老桥不会自己更新）
2. **预设**（必须）：浏览器打开「初始」新标签页 → `Ctrl+F5` 强刷一次（网页要拿到 v2.0.0 宿主）→ ⌘K → 导入预设 → 选 `初始SMTC音乐预设.cshz`
   - **旧版音乐预设先删除再导入**（dock 上出现 ♪ 音乐按钮即成功）
3. **歌词源**（可选，解锁逐字歌词）：把 `初始歌词源-1.0.0.plugin` 放进 BetterNCM 的 `plugins` 文件夹 → 完全退出并重启网易云音乐
   - 不装插件：播放控制/封面/进度全部正常，只是没有歌词区

## 二、面板能做什么

- dock 栏 ♪ 按钮：点击弹出音乐面板；再点/Esc/点空白处/面板右上收起键关闭
- 与内建面板（待办/便签/番茄钟/设置）互切：同一套连续切换动画
- 播放/暂停/上一首/下一首；进度条按住拖动 seek（松手立即生效）
- 封面三重保障：SMTC 封面 → 网易云封面 → 默认唱片
- 逐字歌词：当前词按进度扫色（卡拉 OK），行滚动居中，当前行下方显示翻译
- ⌘K 命令：音乐：播放/暂停、下一首、上一首、正在播放什么

## 三、常见问题

- **进度不走/不能拖动** → 桥还是旧版（v1.2.0 及以前）。网易云的 SMTC 位置字段整首歌不上报，v1.3.0 起桥做时钟补偿；请整目录替换新桥后重开浏览器标签页
- **面板显示「未连接」** → 桥没启动或被安全软件拦了 127.0.0.1:20754；双击启动 bat 后看窗口是否打印监听行
- **没有歌词区** → ①插件没装/网易云没重启；②这首歌在网易云没有歌词（纯音乐/部分外语歌）；两种情况面板自动收窄，其余功能不受影响
- **网页改版后行为怪** → Ctrl+F5（Service Worker 可能缓存旧脚本）
- **扩展版** → 重装 v2.0.0 扩展 zip（v2.0.0 与旧版差异较大，必须重装）
- **bat 窗口报错英文** → 复制窗口内容反馈；窗口提示 PORT IN USE 表示已有一个桥在跑，先关旧的

## 四、给预设开发者的音乐 API（v2.0.0）

「初始」把 SMTC 检测、歌词解析、时间戳对齐、进度插值全部内建，你的预设**只写样式**：

```js
// 部件/页面/脚本里（chushi.music，同步 now + 离散 subscribe）
chushi.music.subscribe(function (s) {
  // s: {connected, app, title, artist, album, cover, coverUrl,
  //     playing, duration, lyricRev, lyric:{mode:1|2, lines:[{s,e,t,tr,w?}]}}
}); // 订阅即回推
var n = chushi.music.now(); // rAF 每帧调用：
// {position, duration, progress, playing, lineIndex, wordIndex,
//  wordProgress, lineProgress, lineText, lineTr, wordText} —— 全部预计算好
chushi.music.seek(90.5);   // 秒；成功自动乐观重锚
chushi.music.toggle();     // play/pause/toggle/next/prev
```

低层 `chushi.smtc`（get/control/subscribe）保持兼容；新预设建议一律 `chushi.music`。
完整文档见「初始」应用内 ⌘K → 预设开发文档 §12。

## 五、隐私与安全

- 桥只监听 `127.0.0.1:20754`（本机回环），不访问外网；歌词源插件只把当前曲目歌词推给本机桥
- 预设面板跑在沙箱 iframe（不透明源），拿不到页面数据/localStorage/Cookie
