# 初始 · Start v8.7.36 交付说明（beta）

## 本包内容
- ChuShi-NewTab-v8.7.36.zip —— 扩展本体（本版：弹窗快捷面板扩容+收藏书签+浮窗残影根治）
- ChuShi-CloudSnapshot-v8.7.36.zip —— 云端快照载荷
- 初始SMTC音乐预设.cshz —— SMTC 桥接音乐面板预设（存量）
- 初始网易云播放器预设.cshz —— 网易云 dock 弹出播放器预设（存量）
- 焕新示例预设.json —— 八维焕新示例预设（存量）
- ChuShi-Music-Bridge-8.4.0.zip —— 音乐桥插件（存量）
- ChuShi-Lyric-Source-7.3.0.plugin —— 歌词源插件（存量）
- SHA256SUMS.txt —— 全文件校验和

## v8.7.36 更新
1. 扩展弹窗快捷面板扩容：首行新增「书签」「收藏此页」——收藏的网页在快捷服务面板磁贴下方滚动即达（常驻与抽屉两样式通用）
2. 弹窗内新增「壁纸压暗程度」滑杆（掠影壁纸 0–200%，已开页面实时跟随）
3. 弹窗内新增「显示 Dock 栏」开关（关闭后底部 Dock 不再显示，实时跟随）
4. 移除网易云播放器预设后悬浮音乐卡残影不退散的根治（卡片壳补上隐没分支）
5. 弹窗内新增「固定到顶栏」引导：Chrome 安全策略要求手动固定一次（点工具栏拼图图标 → 「初始」右侧图钉），之后图标常驻

## 安装
1. 解压 ChuShi-NewTab-v8.7.36.zip（或直接以 zip 形态加载）
2. Chrome 打开 chrome://extensions → 开发者模式 → 加载已解压/拖入 zip
3. 新标签页 → 设置 → 预设 → 导入 初始网易云播放器预设.cshz（老用户直接更新预设）

## 备注
- 播放器需网易云音乐接口可达；扫码登录后可看我的歌单、VIP 歌曲跟账号权限走
- 书签数据存本地（start:bookmarks），弹窗收藏/删除与新标签页书签区实时同步
