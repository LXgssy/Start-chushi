# 初始音乐桥 · 独立版（ChuShiBridge Standalone）v2.0.3

把网易云音乐桌面客户端「正在播放」的歌曲暴露给「初始」起始页
（https://lxgssy.github.io/Start-chushi/ 或其 Edge/Chrome 扩展版），
并提供播放控制（播放/暂停/上下曲/进度/音量/静音）。

**本版本不依赖 BetterNCM / chromatic 任何框架**——BetterNCM 已停更于网易云
（最后一版 1.3.4 发布于 2024-10，无法适配新客户端），本程序改用
「CEF 调试端口」方案，不 hook 网易云任何内部函数，**不随网易云升级而失效**。

## v2.0.3 相对 2.0.0/2.0.1 的修复

- **网易云运行中也可直接安装**：安装器检测到网易云在跑会自动关闭它，
  装完自动带调试端口重启（不再需要手动关闭后再装）；
- **修复新版网易云附加失败**：页面识别判据从单一 `legacyNativeCmder`
  放宽为三路（cmder / webpackJsonp / webpackChunk* / orpheus 页面特征），
  适配网易云 3.x 新内核；
- **修复大响应分片丢失**（WebSocket continuation 帧聚合 bug）；
- **修复 --kill-ncm 时序**（不再误杀刚代启的带参实例）；
- **诊断更细**：`/api/debug` 新增 `attach` / `attachDetail` 字段，
  bridge.log 会记录每次附加失败的具体环节与原因；
- **修复中文安装目录**：config.json 的 `\uXXXX` 转义路径现在能正确解析；
- **CDP 通道重构（v2.0.3）**：改用 browser 端点 + Target.attachToTarget(flatten) 会话模式——实测 CloudMusic CEF 对页端点直连会在握手后立即断开（此前「初始连不上」的直接原因），页端点保留为回退；close 帧状态码/原因会记录进诊断；
- 页内桥兼容 webpack4 / webpack5 双打包器。

## 一键安装（推荐）

1. 解压本压缩包到任意目录；
2. 双击 **安装初始音乐桥.bat**——**网易云正在运行也没关系**，安装器会自动
   关闭并在装完后带参重启（全自动，无需手动关网易云）；
   网易云装在受保护目录时会弹 UAC 提权窗，请点「是」；
3. 安装完成后网易云音乐自动重启，桥接服务就绪（窗口显示服务就绪即成功）；
4. 打开「初始」→ Dock 栏音乐按钮（或网页版音乐面板）→ 自动连接。

安装内容（全部可一键卸载还原）：

| 组件 | 位置 | 作用 |
|------|------|------|
| ChuShiBridge.exe | `%LOCALAPPDATA%\ChuShiBridge\` | 桥接主体：附加网易云页面、采集播放状态、提供本机 HTTP 服务 |
| msimg32.dll | 网易云安装目录 | 装载器：让你双击网易云原图标也能开启桥接（已备份原文件如有） |
| 初始音乐桥.lnk | 桌面 / 可选自启 | 启动桥接（会自动带参启动网易云） |

## 工作原理

```
「初始」(网页/扩展)  ──HTTP 127.0.0.1:10754──▶  ChuShiBridge.exe
                                                  │ CEF 调试协议 (CDP)
                                                  ▼
                                        网易云主页面 (window.__chushiBridge)
                                          Redux store + 原生播放事件 + 媒体元素
```

- **启动器**：以 `--remote-debugging-port=18754` 代启网易云（或由 msimg32 装载器
  保证你手动启动网易云时端口常开）；
- **CDP 附加**：在网易云主页面注入页内桥脚本，从内部 Redux store、原生播放事件
  （PlayState / PlayProgress / Seek）与页面媒体元素三路采集「正在播放」；
- **本机服务**：在 `127.0.0.1:10754`（被占用自动顺延）暴露与「初始」v1.7.5+
  完全兼容的 API（`/api/ping`、`/api/status`、`/api/control`、`/api/debug`）。

## 安全设计

- HTTP 服务只绑定 **127.0.0.1**，局域网内其他设备无法访问；
- **Origin 白名单**：仅允许浏览器扩展、「初始」线上域名与本机地址读取，
  其他网站的跨源请求会被拒绝；
- 控制命令白名单校验（仅 8 种固定动作），请求体 ≤4KB，无任何文件写入网易云目录
  （除装载器本体）；
- CDP 调试端口也只绑定 127.0.0.1（Chromium 默认行为），且仅本机可连。

## 常见问题

**Q: 安装时窗口闪退 / 装载器没装上？**
网易云装在受保护目录时会弹 UAC 提权窗，请点「是」。

**Q: 「初始」一直显示未连接？**
①确认 ChuShiBridge 窗口开着且显示「已附加网易云页面」；
②浏览器地址栏访问 `http://127.0.0.1:10754/api/debug`，
把输出发给开发者即可精确定位——重点看 `attach` 字段：
`ok`=已附加（应能连接）/ `probe-miss`=页面判据未命中 / `ws-fail`=调试通道
握手被拒 / `eval-*`=求值失败（详情见 `attachDetail`）；
③同时把 `%LOCALAPPDATA%\ChuShiBridge\bridge.log` 全文一并保存，
新版日志会记录每次附加失败的具体环节；
④网页版首次连接时浏览器可能弹「访问本地网络」权限，请允许（扩展版无需）。

**Q: 你双击网易云原图标没效果？**
装载器生效的表现是网易云照常启动且桥接自动就绪（无感）。
若未安装装载器（32 位网易云/手动跳过），请始终通过「初始音乐桥」快捷方式启动。

**Q: 之前装过 BetterNCM / chromatic？**
安装器会自动备份并替换其 msimg32.dll（备份为 `msimg32.dll.chushi-backup`）；
卸载时自动还原。两者不可共存（劫持位相同）。

**Q: 改端口？**
编辑 `%LOCALAPPDATA%\ChuShiBridge\config.json`（`cdp` 字段）后重启桥接；
HTTP 服务端口固定 10754 起顺延，「初始」默认地址无需改动。

## 卸载

双击 **卸载初始音乐桥.bat**，或运行
`%LOCALAPPDATA%\ChuShiBridge\uninstall.bat`——
桥接器、装载器（自动还原备份）、快捷方式全部移除，网易云恢复原状。

## 系统要求

- Windows 10/11 x64
- 网易云音乐 3.x（新版客户端即本程序的目标场景；32 位旧版仅支持桥接器代启模式）
- 「初始」v1.7.5 或更新版本
